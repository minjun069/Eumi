# AI 작업 지침

AI 코드·문서의 작성·수정·검토에 적용한다. 공통 규칙과 지침 유지 관리는 [프로젝트 지침](../../AGENTS.md), 현행 명세는 [문서 목록](docs/README.md)을 따른다.

| 작업 | 시작 전 필수 참조 | 완료 조건 |
| --- | --- | --- |
| 코드 작성·수정·검토 | [코드 작업 지침](docs/coding-guide.md), 관련 명세, 대상 README·코드·테스트 | [변경·검증·완료](docs/coding-guide.md#4-변경검증완료)의 설계 대조와 동작 검증을 각각 확인 |
| 런타임·에이전트 문서 작성·수정·검토 | [문서 작성 지침](docs/writing-guide.md), 관련 현행 명세·최신 사용자 수정본 | [수정과 검수](docs/writing-guide.md#3-수정과-검수)의 내용 대조와 참조 검사를 완료 |
| 업무 기획·에이전트 설계·관련 문서 | [업무 범위](docs/agent/scope.md), 문서 작업의 필수 참조 | 사용자 업무·에이전트 역할·실행 조건·미확정 사항을 구분 |

코드와 문서를 함께 바꾸면 두 작업 기준을 모두 적용한다. 완료 보고에는 적용한 기준, 실제 대조·검증 결과, 미검증 사항을 짧게 남긴다.
