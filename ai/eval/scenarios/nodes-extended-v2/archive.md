# 확장 시나리오 보관본

보관일: 2026-11-12. 상태: 현재 기본 묶음의 실행·집계 대상에서 제외.

이 폴더는 기본 시나리오로 범위를 좁히기 직전의 데이터셋을 원본 그대로 보관한다. 실패·자료 부족·재작성과 특정 노드의 부분 사례를 다시 검토할 때 사용한다. 현재 평가에는 [기본 데이터셋](../nodes/README.md)을 사용한다.

| 보관 자료 | 수량 |
| --- | ---: |
| 전체 경로 | 23 |
| 고유 노드 사례 | 375 |
| 전체 경로의 노드 실행 | 320 |
| 부분 사례 그룹 | 81 |
| 부분 사례에만 사용된 노드 사례 | 125 |

[기존 설명](README.md)과 [기존 검증 결과](validation.json)는 당시 입력·실행 코드에 대한 기록이다. 현재 실행 흐름과 평가 기준에 대한 통과 결과로 사용하지 않는다. 원본 보관 여부는 [파일 해시 목록](archive-manifest.json)으로 확인한다. 보관본의 생성·실행 명령을 현재 기본 데이터셋에 적용하지 않는다.
