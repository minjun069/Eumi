### 보고서 시각화 설명

> 도곡1동의 12월은 10~11월의 행동 이상 신호 완화가 유지되지 못하고 다시 커진 구간이다. 점수는 9월 51.85점에서 10월 47.72점·11월 47.82점으로 낮아졌다가 12월 53.06점으로 다시 커졌고, 전월보다 5.24점 높다. 따라서 최근 5개월은 지속적인 누적 상승보다 완화 뒤 재확대된 패턴으로 해석되며, 이 점수만으로 실제 활동 감소나 개인의 고립 악화를 뜻하지는 않는다.
> 현재 점수의 주요 설명축은 고령층 내부의 성별 구성과 남녀 활동 변화율의 관계로, 고령층 전체의 활동 감소로 한데 묶어 해석할 근거는 부족하다. 고령층 성별 변화율 격차의 기여도는 0.26→2.31점, 고령층 남성 비중은 -0.05→1.37점으로 커져 12월 양의 기여도 상위 두 지표가 된 반면, 연령 엔트로피(-1.43→-0.11점)와 주말·주중 변화율 격차(-1.47→-0.11점)의 음의 기여도는 0에 가까워졌다. 이 기여도는 해당 지표만 같은 도시·같은 달 중앙값으로 바꿨을 때와의 점수 차이이므로 현재의 성별 활동 관계가 주요 이상 신호로 설명된다는 뜻이며, 실제 어느 성별의 활동이 줄었는지나 전체 점수 상승의 원인별 비중을 알려주지는 않는다.
> 현재 격자 분포는 동 전체에 같은 평가를 적용하기보다 높은 점수대에서 검토 대상을 좁힐 근거를 준다. 조회된 105개 격자의 점수는 38.36~54.16점이며, 40점 이상 45점 미만이 63개(60.0%), 50점 이상은 5개(4.8%)로 다수의 점수대와 소수 상단이 구분된다. 이는 현재 수준의 차이를 보여줄 뿐, 50점이 위험 판정선이거나 상단 격자들이 공간적으로 모여 있다는 뜻은 아니며 12월 상승이 그 5개 격자에서 발생했는지도 이 분포만으로는 알 수 없다.

## 보강한 분석 근거

기존 스냅샷의 네 관측 데이터셋은 그대로 유지했다. 사본에만 [지표 정의 자료](snapshots/definitions.json)를 추가하고 기존 조회 도구로 읽어 실제 작업 이력에 남겼다. 정의는 12개 행동 지표와 기여도 산식의 총 13행이다.

- [지표 이름과 공통 산식](../../../../data/pipeline/common/bh_indicators.py)
- [행정동 지표 산출](../../../../data/pipeline/m3_indicator/batch_bh_region_indicators.py)
- [행동 점수 기여도 계산](../../../../data/pipeline/m4_analysis/batch_bh_contribution.py)

기여도는 현재 점수에서 해당 지표 하나를 같은 도시·같은 달의 중앙값으로 바꿔 계산한 점수를 뺀 값이다. 어떤 지표 축이 점수에 민감하게 작용하는지는 설명할 수 있지만, 기여도를 더해 전체 점수 변화의 원인을 분해하거나 실제 남녀 활동의 증가·감소 방향으로 바꿀 수는 없다. 원값 방향이 필요한 주장만 제한하며 지표 축의 해석까지 중단하지 않는다.

이 자료원 추가는 검토용 입력 보강이다. 운영 DB에 지표 정의 조회가 연결됐다는 뜻은 아니다. 실제 활동량 원값을 새로 만들거나 시설·생활권 변화의 원인을 확정하지 않았다. 격자 구간은 분포를 요약하기 위한 구분이며 위험 판정 임계값이 아니다.

말투·문장 순서·동등한 결론 표현은 허용한다. 사용자에게 평가 항목을 질문하게 하거나 예시 문장을 그대로 복제하도록 요구하지 않는다. 이전 사본처럼 숫자와 확인 제안은 맞지만 결론이 빠진 답변을 미달 예시에 포함했다.
