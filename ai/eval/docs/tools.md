# 도구 평가

상태: 검토용 명세.
수정일: 2026-11-12.

도구의 개별 호출이 정해진 입력을 처리하고 실제 결과를 정확히 반환하는지 평가한다.
평가 절차와 기록 양식은 [평가 방법](methods.md)을 따른다.

실행 정보(`State`)는 요청·자료·작업 이력·공개 응답·실행 상태를 보관하는 기록이다.
필드 정의는 [실행 정보 명세](../../docs/agent/state.md)를 따른다.

## 1. 평가 대상

### 1.1 데이터 검색 및 조회

T01: 등록 자료의 조건별 조회와 결과 반환을 평가한다.

준비한 자료를 메모리로 제공한 조회 처리·오류 변환 검사를 통과하면 **합성자료 기반 조회 처리 검증 완료**로 보고한다. 서비스와 같은 구조의 별도 DB에 평가 원본을 적재하고 실제 서비스 조회 경로의 검사를 통과하면 **평가 DB 기반 서비스 조회 연동 검증 완료**로 보고하며 사용한 사례·계정·서버 범위를 함께 명시한다. 정상 조회만으로 실제 장애 처리나 운영 성능까지 확인한 것으로 보고하지 않는다. 실행기·채점 로직의 한계는 [실행기의 평가 범위와 한계](runner.md#평가-범위와-한계)를 따른다.

#### 준비 자료

| 기준 자료 | 실행 증거 |
| --- | --- |
| 등록 자료원, 조건별 정답 행, 출처 메타데이터 | 실제 입력, 조회 기록, 응답 |

### 1.2 데이터 가공

T02: 지정한 연산과 계산 결과 반환을 평가한다.

#### 준비 자료

| 기준 자료 | 실행 증거 |
| --- | --- |
| 원본 자료, 연산 순서, 결측·결합·반올림 규칙, 독립 계산값, 허용 오차 | 실제 입력, 계산 결과, 응답 |

### 1.3 시각화 설정 검사

T03: [Tableau 명세](../../docs/agent/tableau.md)의 등록 규칙에 따른 입력 검사와 프론트 전달용 산출물 반환을 평가한다.

#### 준비 자료

| 기준 자료 | 실행 증거 |
| --- | --- |
| 배포 카탈로그, 시작 이벤트가 있는 `State`, 기대 판정·산출물 | 실제 입력, 검사 결과, 반환 산출물 |

## 2. 기능 평가

아래 검사를 각 도구의 시험 사례에 적용한다. 
- 사례별 적용 여부와 기대 결과는 실행 전에 정한다.
- 실패한 세부 항목과 원인을 기록한다.
### 2.1 입력

| 검사 ID | 검사 항목     | 판정 단위 | 성공 기준                                                                         | 측정 방법                                                                 |
| ----- | --------- | ----- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| T-I.1 | 입력 처리 적합성 | 입력 항목 | 계약의 수용 조건을 충족하면 수용하고, 도구가 검사하도록 정한 조건을 위반하면 거부한다. 위반 입력을 임의 값으로 보정해 실행하지 않는다. | 입력 조건표의 기대 판정과 실제 수용·거부를 대조한다. 조건을 하나씩 위반한 입력의 거부 사유와 실제 실행 여부를 확인한다. |

### 2.2 출력

| 검사 ID | 검사 항목     | 판정 단위       | 성공 기준                                                                                                               | 측정 방법                                                                                                                                                                   |
| ----- | --------- | ----------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-O.1 | 처리 결과 정확성 | 결과 항목       | 처리 결과와 반환한 값·단위·적용 조건·건수·필수 필드가 기대 결과에 맞는다.<br><br>시각화 설정 검사의 경우, 적합한 요청만 산출물로 반환하고, 부적합이면 사유와 `null` 산출물을 반환해야 한다. | - 정답 행, 독립 계산값, 등록 조건별 기대 판정·산출물과 대조한다. <br>- 수치는 사전 허용 오차를 적용한다. <br>- 도구 내부 결과와 응답의 일치만으로 통과시키지 않는다.<br>- 시각화 설정 검사의 경우, 적합 여부와 산출물의 뷰·주소·대상 시트·매개변수·필터·한계를 대조한다.<br> |
| T-O.2 | 처리 상태 구분  | 호출          | 해당 도구의 정상·자료 없음·부적합·실행 오류·확인 불가를 실제 결과대로 구분하고, 반환 결과나 예외로 사유를 제공한다.                                                 | - 처리 기록과 반환 상태·사유를 대조한다.<br>- 정상 0건과 읽기 실패, 사용자 설정 부적합을 구분한다.                                                                                                           |
| T-O.5 | 출처 정보 정확성 | 필수 출처 정보 항목 | 필수 출처의 주소 또는 내부 참조가 존재하고, 대상·시점·버전이 실제 사용 자료 또는 등록 설정과 일치한다.                                                        | - 기준 자료의 필수 출처 목록·메타데이터와 반환 정보를 대조한다.<br>- 필수 출처 누락도 실패로 판정한다.<br>- 시각화의 출처·등록 설정 버전은 배포 카탈로그와 대조하며 원자료 버전과 구분한다.                                                       |

- 동일 출력 항목의 동일 판정은 중복 집계하지 않으며, 서로 다른 오류는 각각 기록한다.

## 3. 평가 지표

도구별로 시험 묶음 종료 시 집계한다.

- 반복이 필요한 사례는 같은 입력·자료·구성·환경과 반복 횟수를 시험 전에 정한다.
- 예상 밖 실행 실패와 원인은 사례 결과에 남긴다.

### 3.1 기능 지표

|지표|적용 검사|측정 단위|분자|분모|측정 방법|
|---|---|---|---|---|---|
|필수 사례 통과율|T-I.1, T-O.1·.2·.5|필수 사례|통과한 필수 사례 수|평가 대상으로 정한 필수 사례 수|사례별 적용 검사 판정으로 분자 ÷ 분모|

- 사례 ID별로 한 번 집계하며, 미실행·미판정 사례는 분모에 남기고 각각의 건수와 사유를 별도로 표시한다.
- 분모가 0이면 산출 불가다.

### 3.2 운영 지표

| 지표 ID | 지표      | 측정 단위 | 측정 방법                                   |
| ----- | ------- | ----- | --------------------------------------- |
| O01.1 | 호출 응답시간 | 도구 호출 | 호출 시작부터 반환까지 측정해 정상·오류별 중앙값과 p95를 기록한다. |

- 미종료 호출은 응답시간 통계에서 제외하고 경과 시간을 기록하며, 실행 한도 초과는 실패로 판정한다.

## 4. 합격 판정

|구분|지표|합격 조건|보류 조건|
|---|---|---|---|
|기능|필수 사례 통과율|모든 필수 사례와 예정한 반복에서 적용 검사 전부 통과|필수 사례·반복의 미실행·미판정 또는 계약·기준값·실행 증거 부족|
|운영|호출 응답 시간|성능 목표를 지정한 시험의 응답시간 기준 충족|성능 판정 대상의 필수 측정·반복 미실행·미판정 또는 시험 조건·목표 미확정|

#### 기능 판정기준

- 예정한 모든 반복에서 적용 검사를 통과해야 그 사례를 통과로 인정한다.

#### 운영 판정기준

- 대상 도구·대표 자료 크기·반복 횟수·실행 환경·판정 통계값·최대 허용값을 확정해야 한다.
