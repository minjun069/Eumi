# 서비스 검증

상태: 평가 대상·범위 확정, 세부 설계 미정. 수정일: 2026-11-11.

복지 담당자가 서비스를 사용해 지역 분석의 근거와 한계를 이해하고 지역 탐색 업무를 수행하는 데 도움을 받는지 검증한다. [내부 평가](methods.md#평가-단위와-책임)의 도구·노드·에이전트 실행 평가와 구분한다.

## 1. 평가 대상과 범위

| 구분 | 내용 |
| --- | --- |
| 평가 대상 | 복지 담당자가 설명·시각화·대화·화면을 함께 사용하는 서비스 이용 과정 |
| 업무 지원 | 지역 간 차이와 비교 근거를 찾고, 관측 사실과 해석 한계를 이해하는 데 주는 도움 |
| 사용 경험 | 필요한 정보를 얻는 데 드는 시간·조작·추가 질문 등의 부담과 사용 만족 |
| 책임 범위 | [업무 범위](../../docs/agent/scope.md)에 따른 근거 탐색·이해 지원. 방문 지역·우선순위의 최종 결정은 담당자 역할 |

응답 내용의 정확성은 노드 평가에서, 한 작업의 내부 실행과 성능은 에이전트 실행 평가에서 확인한다. 서비스 검증은 실제 사용자의 수행과 경험을 대상으로 하며, 화면·대화 설계의 영향을 포함하므로 결과를 특정 에이전트의 성능으로만 해석하지 않는다.

## 2. 미정 사항

참여자, 업무 시나리오, 비교 조건, 검사 항목, 측정 방법, 지표·목표값과 합격 기준은 미정이다. 위 범위의 세부 평가를 설계한 뒤 검증하며, 현재는 시험 절차나 합격 판정을 확정하지 않는다.
