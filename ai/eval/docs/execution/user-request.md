# 사용자 요청 처리

상태: 검토용 명세. 수정일: 2026-11-12.

[에이전트 실행 평가](README.md) · [공통 평가 기준](common.md)

## 평가 범위

한 질문에 대한 에이전트 실행에서 노드 간 상태 전달·전이, 공유 예산, 실행 중단과 호출자 반환을 확인한다.

| 항목 | 평가 범위 |
| --- | --- |
| 입력 | 에이전트에 제공한 질문·관련 대화·화면 문맥·확인된 자료와 초기 실행 상태 |
| 시작 | 준비된 입력을 받아 사용자 요청 처리 에이전트의 작업 목적 파악으로 진입하는 시점 |
| 종료 | 최종·부분·질문 결과와 실행 상태를 호출자에게 반환하거나 오류·취소로 실행을 마친 시점.<br>미종료 실행은 관측 종료 시점까지 기록 |

실행 단위·재진입 구분·서비스 동작 제외는 [실행 단위와 경계](README.md#실행-단위와-경계), 노드 내부 작업과 실행 검사의 책임 구분은 [판정 연결](README.md#판정-연결)을 따른다.

업무 근거는 [사용자 요청 처리 에이전트](../../../docs/agent/components.md#33-사용자-요청-처리-에이전트), [실행 흐름](../../../docs/agent/workflow.md#2-에이전트-공통-실행-흐름), [실행 상태](../../../docs/agent/state.md)다.

## 공통 실행 검사 적용

검사 정의와 판정은 [공통 실행 검사](common.md#공통-실행-검사)를 따른다. 아래 표는 사용자 요청의 적용 경계이며 별도 판정으로 중복 집계하지 않는다.

| 공통 검사           | 관찰 범위   | 검사 대상 | 평가 관점 | 실행 상황                    | 사용자 요청 적용 경계                                                                                                                                                                                |
| --------------- | ------- | ----- | ----- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EX-1 노드 간 전이    | 단계 간 연결 | 호출·전이 | 규칙 준수 | 정상, 자료 부족, 오류·재시도, 한도·취소 | 목적 파악·작업 실행 후 진행 판단으로 이동한다.<br>진행 판단이 정한 추가 작업·응답 작성·정보 요청으로 바로 연결한다.<br>일반 최종 응답과 질문은 이번 호출의 반환으로 연결한다.                                                                                    |
| EX-2 노드 간 상태 전달 | 단계 간 연결 | 상태·이력 | 규칙 준수 | 정상, 자료 부족, 오류·재시도, 한도·취소 | 직전 노드가 반환한 요청·대화·이력·응답을 다음 노드의 진입 상태와 대조한다.<br>노드 사이에서 원본·참조·기존 이력을 누락하거나 정해진 전환 외의 값으로 바꾸지 않는다.<br>정해진 실행 정보 갱신은 구분하고 공유 예산은 EX-3 판정에 연결한다.                                                |
| EX-3 공유 예산 유지   | 단계 간 연결 | 상태·이력 | 규칙 준수 | 정상, 자료 부족, 오류·재시도, 한도·취소 | 노드·상하위 호출 경계와 보존 상태로 재진입하는 경계에서 주어진 한도·누적 사용량을 이어 쓴다.<br>한도를 다시 초기화하거나 이전·하위 사용량을 중복 합산하지 않는다.                                                                                              |
| EX-4 중단과 종료 경로  | 실행 전체   | 호출·전이 | 규칙 준수 | 오류·재시도, 한도·취소            | 실행 계층의 한도·취소·처리되지 않은 실행 오류가 정해진 후속 진입 차단과 종료로 이어지는지 확인한다.<br>한도 후 종료 응답은 [공통 EX-4](common.md#공통-실행-검사)의 공유 종료 예산을 따르며, 하위에서 이미 사용한 예산도 포함한다.<br>종료 응답 실패·예산 소진 뒤에는 추가 호출 없이 기존 결과·사유를 반환한다. |
| EX-5 최종 반환 경계   | 실행 전체   | 반환 결과 | 규칙 준수 | 정상, 자료 부족, 오류·재시도, 한도·취소 | 최종 노드 결과 또는 실행 계층의 종료 결과가 호출자에게 전달되는 경계를 대조한다.<br>응답·선택 산출물·실행 상태·종료 사유를 보존하고, 부분·질문·실패·취소를 완료로 바꾸거나 이전 호출 결과를 반환하지 않는다.                                                                    |

자료가 충분하다는 판단은 작업 실행을 거치지 않고 응답 작성으로, 사용자만 제공할 정보가 필요하다는 판단은 사용자 정보 요청으로 연결한다.

질문 응답과 내부 상태인 `waiting_input`을 반환하면 이번 실행을 끝내며, 사용자 답변을 기다리는 실행을 남기지 않는다. 후속 질문은 별도 실행이다.

## 평가 준비와 기록

입력·기대 경로·반환 결과·실행 예산·반복 횟수·적용 검사를 실행 전에 정하고, [전체 실행 시험과 기록](common.md#전체-실행-시험과-기록)에 따라 노드 경계와 호출자 반환의 증거를 수집한다.

## 평가 지표

### 기능 지표

[공통 기능 지표](common.md#기능-지표)를 적용 EX 검사와 사전에 정한 필수 사례에 사용한다.

### 운영 지표

한 질문의 진입부터 반환·종료까지 [공통 운영 지표](common.md#운영-지표)를 적용한다. 재진입 시에는 이번 진입 이후 소비량만 집계하며, 하위 실행의 중복 합산 방지·측정 누락 처리·결과 유형별 구분도 같은 기준을 따른다. 사용자 답변 대기 시간은 합산하지 않는다.

## 합격 판정

적용 EX 검사의 기능 합격과 실제 연결 환경의 운영 합격은 [공통 합격 판정](common.md#합격-판정)에 따라 각각 판정한다. 실행 한도 준수는 EX-3·4의 기능 기준으로, 성능·안정성 목표는 운영 기준으로 구분한다.

## 남은 확인 사항

실행 증거·운영 조건의 확인 시점과 미확정 사항에 따른 판정 보류는 [공통의 남은 확인 사항](common.md#남은-확인-사항)을 따른다. 문서상 기준과 자동 채점 지원 범위는 [단위 평가 실행기의 제약](../runner.md#7-현재-제약과-후속-작업)에서 구분한다.
