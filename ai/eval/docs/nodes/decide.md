# 작업 진행 판단

상태: 검토용 명세. 수정일: 2026-11-12.

[노드 평가 개요·지표·합격 판정](README.md) · [공통 평가 기준](common.md)

## 평가 범위

작업 진행 판단 노드(N03)가 첫 작업 전과 작업 후에 현재 정보의 충분성·필요한 정보를 판단해 반환한 진행 방향과 이유를 평가한다.

## 출력 형식

출력 형식은 [정형 평가 정의](decide.json)의 `output-format` 원칙을 따른다.

## 전용 검사

검사 정의의 단일 원본은 [정형 평가 정의](decide.json)다. 이관 내용은 [원본 Markdown 보관본](originals/decide.md)과 대조한다.

## 진행 판단 조건표

상황별 진행 판단 조건과 진행 방향은 [정형 평가 정의](decide.json)의 `next-direction` 원칙을 따른다.
