# 공통 평가 기준

상태: 검토용 명세. 수정일: 2026-11-12.

[노드 평가 개요·지표·합격 판정](README.md)

현재 N 정형 검사에 공통으로 적용하는 모델 출력 형식·내용 검사와 판정 기준을 정의한다.
각 노드의 전용 검사와 함께 적용한다.

## 노드 검사의 세 축

노드 검사의 세 축과 평가 순서는 [정형 평가 정의](common.json)의 `evaluation-order` 원칙을 따른다.

## 출력 형식의 공통 기준

출력 형식의 공통 기준은 [정형 평가 정의](common.json)의 `output-format` 원칙을 따른다.

## 공통 검사

검사 정의의 단일 원본은 [정형 평가 정의](common.json)다. 이관 내용은 [원본 Markdown 보관본](originals/common.md)과 대조한다.

전용 검사는 해당 노드의 목표·선택·판단·질문과 산출물 요구를 담당한다.
공통 내용 검사는 그 밖에 직접 작성·추가한 설명·해석과 하위 결과의 전달 부분에 적용한다.
같은 문장이 선택 이유와 공개 설명에 반복되면 담당 판정과 증거를 연결한다.
노드 내부의 자료·상태 갱신·이력 기록은 [노드 책임과 현재 검사 범위](README.md#대상)를 따른다. 노드가 반환한 자료·상태·이력을 다음 단계에 전달하며 누락·변경한 문제는 [에이전트 실행 평가](../execution/common.md#공통-실행-검사)에서 확인한다.

## 준비 자료

검사별 입력을 [검사 입력 구분과 목록](../methods.md#검사-입력)에 따라 준비한다.
[입력 선정 원칙](../methods.md#입력-선정-원칙)에 따라 LLM 검사에는 해당 호출의 실행 입력 전체를 원문으로 제공하고, 규칙 검사와 검사 대상 출력은 필요한 범위와 원본 위치를 기록한다.
출력 형식은 위 [공통 기준과 노드별 정의](#출력-형식의-공통-기준)를 사용한다.
작업 선택의 시각화 입력 프로필은 실행 전에 해당 뷰의 필수 이름·자료형을 고정한다.
LLM 기반 검사는 실행 당시 입력과 실제 출력을 해당 검사·역할별 기준에 대조한다.
LLM 기반 검사의 기준 사례와 사람 검토는 [LLM 판정 절차](../methods.md#llm-판정-절차)를 따른다.

## 노드 검사 판정

개별 항목의 판정 기준은 [공통 판정 원칙](../methods.md#4-판정-원칙)을 따른다. 노드 실행의 판정 기록·세부 항목 구성·전체 판정 집계는 [정형 평가 정의](common.json)의 `node-verdict` 원칙에서 관리한다.
