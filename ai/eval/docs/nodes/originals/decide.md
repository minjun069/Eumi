# 작업 진행 판단

상태: 검토용 명세. 수정일: 2026-11-11.

[노드 평가 개요·지표·합격 판정](README.md) · [공통 평가 기준](common.md)

## 평가 범위

작업 진행 판단 노드(N03)가 확보한 자료와 남은 요구를 근거로 반환한 진행 방향과 이유를 평가한다.

## 출력 형식

N-F.1은 아래 형식과 [공통 형식 기준](common.md#출력-형식의-공통-기준)을 적용한다.

| 필드 | 자료형 | 필수 여부 | 형식 기준 |
| --- | --- | --- | --- |
| `next` | 문자열 | 필수 | 추가 작업 `act`, 응답 작성 `compose`, 사용자 정보 요청 `ask` 중 하나다. |
| `reason` | 문자열 | 필수 | 진행 방향을 선택한 이유와 명시해야 할 부족·실패 사항을 담는다. |

허용된 값 중 상황에 맞는 방향을 골랐는지는 N03-O.3과 [진행 판단 조건표](#진행-판단-조건표)에서 판정한다.

## 진행 판단 조건표

N03-O.3의 진행 판단 기준이다. 부족 사항과 사유의 누락은 N03-O.4, 작성한 내용의 정확성은 N03-O.2에서 확인한다.
조회 가능한 정보는 추가 작업으로 확보하며, 사용자만 제공할 수 있는 필수 정보가 있을 때 사용자 정보 요청을 선택한다.

| 조건 | 기대 판단 |
| --- | --- |
| 응답 작성에 필요한 자료가 모두 확보됨 | 응답 작성 |
| 자료가 부족하지만 허용된 작업으로 보완 가능 | 추가 작업 |
| 사용자만 제공할 수 있는 필수 정보가 누락됨 | 사용자 정보 요청 |
| 허용된 작업과 사용자 답변으로도 보완 불가 | 제공 가능한 결과와 한계를 설명할 응답 작성 |
