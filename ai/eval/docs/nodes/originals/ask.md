# 사용자 정보 요청

상태: 검토용 명세. 수정일: 2026-11-11.

[노드 평가 개요·지표·합격 판정](README.md) · [공통 평가 기준](common.md)

## 평가 범위

사용자 정보 요청 노드(N05)가 반환한 질문이 필요한 정보를 빠짐없이 구체적으로 요청하는지 평가한다.

## 출력 형식

N-F.1은 아래 형식과 [공통 형식 기준](common.md#출력-형식의-공통-기준)을 적용한다.

| 필드 | 자료형 | 필수 여부 | 형식 기준 |
| --- | --- | --- | --- |
| `content` | 문자열 | 필수 | 사용자에게 보여 줄 질문 본문이다. |
| `reason` | 문자열 | 필수 | 해당 정보를 요청하는 이유다. |

별도 질문 수·문장 수·선택지 개수는 요구하지 않는다.
필요한 질문·선택지가 포함됐는지는 N05-O.2, N05-O.3에서 판정한다.
