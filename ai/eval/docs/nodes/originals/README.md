# 노드 평가

상태: 검토용 명세. 수정일: 2026-11-11.

노드가 주어진 입력에 맞는 목표·선택·판단·응답·질문을 출력하는지 평가한다.
[노드 출력과 에이전트 실행](../methods.md#노드-출력과-에이전트-실행)의 책임 구분과 [세 평가 축](common.md#노드-검사의-세-축)을 따른다.
각 검사는 코드로 대조하는 규칙 기반 또는 평가용 언어 모델이 판정하는 LLM 기반 중 한 가지 방식을 사용한다.
방식의 정의는 [검사 방식](../methods.md#검사-방식), 평가 입력의 명칭은 [검사 입력 목록](../methods.md#검사-입력)을 따른다.

## 1. 노드별 평가

### 적용

각 노드의 시험 사례에 전용 검사와 [공통 검사](common.md#공통-검사)를 함께 적용한다.
형식 기준은 [공통 형식](common.md#출력-형식의-공통-기준)과 각 노드 문서의 출력 형식을 사용한다.
필수 내용과 정확성은 해당 입력 상황·역할의 기준을 사용한다.
검사 순서와 실패 시 후속 검사 생략은 [단계별 평가 원칙](common.md#노드-검사의-세-축)을 따른다.

### 기록

검사별 세부 결과는 [노드 검사 판정](common.md#노드-검사-판정)에 따라 기록한다.
같은 대상·조건은 [판정 연결 원칙](../methods.md#검사-범위와-판정-연결)에 따라 중복 채점하지 않는다.

### 대상

검사 대상은 내부 실행 계층이 상태에 반영·변환하기 전의 모델 반환값이다.
실제 호출·상태 반영·이력 기록·전이는 [에이전트의 공통 실행 평가](../execution/common.md#공통-실행-검사)에서 확인한다.

| 평가 대상 | 문서 내용 |
| --- | --- |
| [작업 목적 파악](interpret.md) | 평가 범위·출력 형식·전용 검사·시험 사례 |
| [작업 선택 및 실행](act.md) | 평가 범위·출력 형식·전용 검사·시험 사례 |
| [작업 진행 판단](decide.md) | 평가 범위·출력 형식·전용 검사·시험 사례·진행 판단 조건표 |
| [응답 작성](compose.md) | 평가 범위·출력 형식·전용 검사·시험 사례 |
| [사용자 정보 요청](ask.md) | 평가 범위·출력 형식·전용 검사·시험 사례 |
| [공통 평가 기준](common.md) | 세 평가 축·공통 형식·공통 검사·준비 자료·시험 사례·검사 판정 |

## 2. 평가 지표

모든 지표는 시험 묶음 종료 시 노드별로 집계한다. 보고서 노드는 선정·설명·인사이트 역할도 구분한다.
실제로 실행한 노드만 세며, 응답 작성 안의 개별 작성·검토 모델 호출을 별도 노드 실행으로 더하지 않는다.
비율의 실제 분자·분모 건수, 분모가 0인 경우와 미종료 호출의 처리는 [공통 집계 원칙](../methods.md#51-지표-집계)을 따른다.

### 2.1 기능 지표

| 지표 | 적용 검사 | 측정 단위 | 계산 방법 | 목표값 |
| --- | --- | --- | --- | --- |
| 검사 항목별 통과율 | 각 N 검사 | 노드 실행 1회 | 해당 검사를 통과한 노드 실행 수 ÷ 해당 검사에 통과·실패 판정이 있는 노드 실행 수 | 합격 기준으로 사용하지 않음 |
| 세부 항목 통과율 | 각 N 검사의 세부 항목 | 검사별로 정한 대상·조건 1개 | 해당 검사의 세부 항목 통과 건수 ÷ 해당 검사의 세부 항목 통과·실패 판정 건수 | 합격 기준으로 사용하지 않음 |
| 필수 사례 통과율 | 사례별 적용 N 검사 | 필수 사례 | 적용 검사를 모두 통과한 필수 사례 수 ÷ 기능 판정이 완료된 필수 사례 수 | 전체 필수 사례의 적용 검사 전부 통과 |

- 실패가 확인되면 사례는 실패로 판정 완료한다. 통과는 예정한 모든 반복에서 적용 검사가 모두 통과한 경우에만 인정한다.
- 검사 항목별 통과율과 세부 항목 통과율은 각각의 판정에서 미실행·미판정·비적용을 분모에서 제외한다. 필수 사례 통과율은 기능 판정이 완료되지 않은 사례를 분모에서 제외한다.
- 세부 항목은 검사 ID와 동일한 세부 판정 단위별로 합산한다. 통과율과 함께 통과·실패·미판정·비적용 건수 및 미실행 항목 수를 표시하고, 선행 단계 실패로 생략한 건수를 구분한다. 후속 검사 통과율은 선행 단계를 통과한 결과를 대상으로 한다.
- 실패 판정 없이 미실행·미판정 검사나 미확인 필수 조건이 남은 사례는 검증 미완료로 남긴다. 미완료 사례에서도 판정한 검사·세부 항목의 결과는 각각의 통과율에 반영한다.
- 전체 필수 사례의 완료·미완료 여부, 검사별 미실행·미판정 건수와 미확인 필수 조건은 [검증 완료 현황](../methods.md#52-검증-완료-현황)에 기록한다.
- 검사 항목별 통과율은 해당 검사를 모두 통과한 실행의 비율을, 세부 항목 통과율은 확인한 세부 항목 중 기준을 충족한 비율을 보여 주는 진단용 지표다. 합격은 필수 사례 통과율과 전체 검증 완료 여부로 판단한다.

### 2.2 운영 지표

| 지표 ID | 지표         | 측정 단위    | 계산 방법                                                                                                              | 목표값                   |
| ----- | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------ | --------------------- |
| O02.1 | 기술적 실행 실패율 | 노드 호출    | 기술적 문제로 실패 종료한 호출 수 ÷ 종료된 호출 수                                                                                     | 운영 판정 대상 시험의 실행 전에 확정 |
| O01.1 | 호출 응답시간    | 노드 호출    | 노드 진입부터 반환까지 걸린 시간의 정상·오류별 중앙값·p95                                                                                 | 운영 판정 대상 시험의 실행 전에 확정 |
| O03.1 | 토큰 사용량     | 노드 실행 1회 | 해당 노드가 직접 호출한 모델의 입력·출력 토큰을 각각 합산한다.<br>노드 실행별 합계의 평균·p95를 기록한다.                                                   | 합격 기준으로 사용하지 않음       |
| O03.2 | 모델 호출 수    | 노드 실행 1회 | 해당 노드가 직접 수행한 모델 호출의 실제 시도 횟수를 센다.<br>실패한 호출과 재시도를 포함하며, 노드 실행별 호출 수의 평균·p95를 기록한다.                                | 합격 기준으로 사용하지 않음       |
| O03.3 | 기술적 재시도 횟수 | 노드 실행 1회 | 해당 노드가 직접 수행한 모델·도구·하위 에이전트 호출에서 통신 오류·시간 초과 등 기술적 오류로 추가 시도한 횟수를 센다.<br>최초 시도는 제외하며, 호출 종류별로 노드 실행당 평균·p95를 기록한다. | 합격 기준으로 사용하지 않음       |

p95는 측정값의 95%가 그 값 이하인 지점이다.
기술적 실행 실패율·호출 응답시간의 시험 조건과 목표값은 [운영 시험 준비 기준](../methods.md#2-사례-기록)에 따라 확정한다.
목표값이 미확정이면 해당 운영 지표의 합격 판정을 보류한다.

- 세 사용량 지표는 [에이전트 실행의 호출·단계 사용량](../execution/common.md#운영-지표)과 같은 실행 기록을 노드별로 집계한 진단용 지표다. 현재 합격 판정에는 사용하지 않는다.
- 토큰 사용량과 모델 호출 수에는 해당 노드 내부의 작성·검토·재작성 호출을 포함한다. 하위 에이전트 내부의 모델 호출·토큰·재시도는 해당 하위 노드에만 집계하고, 평가용 모델 호출은 제외한다.
- 기술적 재시도에는 응답 내용 보완을 위한 재작성·재검토나 추가 자료 확보를 위한 새 작업을 포함하지 않는다.
- 세 사용량 지표는 정상·오류로 종료된 노드 실행을 집계한다. 지표별 측정이 누락된 실행은 0으로 처리하지 않고 해당 통계에서 제외하며 누락 건수를 표시한다. 아직 종료되지 않은 실행의 관측 사용량은 별도로 표시한다.
- 토큰 사용량은 입력·출력별로 측정 누락을 확인한다. 노드·역할·모델과 입력 규모를 구분해 비교하며, 사용량이 적다는 이유만으로 기능 품질이 높다고 판정하지 않는다.
