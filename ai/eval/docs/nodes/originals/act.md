# 작업 선택 및 실행

상태: 검토용 명세. 수정일: 2026-11-11.

[노드 평가 개요·지표·합격 판정](README.md) · [공통 평가 기준](common.md)

## 평가 범위

작업 선택 및 실행 노드(N02)가 반환한 작업·호출 대상·입력 인자·선택 이유를 평가한다.

## 출력 형식

N-F.1은 아래 반환 구조·호출 인자와 [공통 형식 기준](common.md#출력-형식의-공통-기준)을 적용한다.
호출 대상의 역할별 허용 범위는 N02-B.2, 인자의 요청 적합성과 자료 참조는 N02-O.3에서 판정한다.

### 반환 구조

| 필드 | 자료형 | 필수 여부 | 형식 기준 |
| --- | --- | --- | --- |
| `name` | 문자열 | 필수 | `query_data`, `process_data`, `validate_visualization`, `interpretation_agent`, `visualization_agent`, `none` 중 하나다. |
| `arguments_json` | 문자열 | 필수 | 아래 호출 인자 객체를 JSON으로 직렬화한 문자열이다.<br>해석 결과가 객체여야 하며, `name=none`이면 빈 객체 `{}`다. |
| `reason` | 문자열 | 필수 | 선택한 작업 또는 호출 생략의 이유를 담는다. |

### 호출 인자

아래 필드는 `arguments_json`을 해석한 객체 안의 필드다.
'텍스트'는 공백 외 문자가 있는 문자열이며, '단일값'은 문자열·유한한 수·불리언·`null` 중 하나다.

| 호출 대상 | 필드 | 자료형 | 필수 여부 | 형식 기준 |
| --- | --- | --- | --- | --- |
| 데이터 조회 `query_data` | `target` | 텍스트 | 필수 | — |
| 데이터 조회 | `version`, `as_of` | 텍스트 | 선택 | — |
| 데이터 조회 | `filters` | 조건 객체 배열 | 선택 | 조건 객체는 아래 정의를 따른다. |
| 데이터 조회 | `fields` | 텍스트 배열 | 선택 | 제공하면 1개 이상이다. |
| 데이터 조회 | `sort` | 정렬 객체 배열 | 선택 | 정렬 객체는 아래 정의를 따른다. |
| 데이터 조회 | `offset` | 정수 | 선택 | 0 이상이다. |
| 데이터 조회 | `limit` | 정수 | 선택 | 1~10,000이다. |
| 데이터 가공 `process_data` | `input_result_id` | 문자열 | 필수 | 가공할 자료를 가진 작업 결과의 ID를 담는다. |
| 데이터 가공 | `operations` | 연산 객체 배열 | 필수 | 1개 이상이며 아래 연산별 구조를 따른다. |
| 데이터 가공 | `missing` | 문자열 | 선택 | `error`, `drop`, `preserve` 중 하나다. |
| 데이터 가공 | `fields` | 텍스트 배열 | 선택 | 제공하면 1개 이상이다. |
| 데이터 가공 | `decimals` | 정수 | 선택 | 0~12다. |
| 시각화 검증 `validate_visualization` | `view_key` | 텍스트 | 필수 | — |
| 시각화 검증 | `parameters` | 텍스트 이름 → 텍스트 값의 객체 | 선택 | 선택한 뷰에 등록된 필수 매개변수는 모두 포함한다. |
| 시각화 검증 | `filters` | 텍스트 이름 → 텍스트 배열의 객체 | 선택 | 제공한 필터별 값은 1개 이상이다. |
| 하위 호출 `interpretation_agent`, `visualization_agent` | `goal` | 문자열 | 필수 | — |

가공 입력의 자료 본문은 런타임이 결과 ID로 찾아 전달한다.
모델은 `data`나 결합할 자료의 `right` 본문을 반환하지 않고 각각 `input_result_id`, `right_result_id`를 사용한다.

#### 조건·정렬 객체

| 객체 | 필드 | 자료형 | 형식 기준 |
| --- | --- | --- | --- |
| 조건 | `field` | 텍스트 | — |
| 조건 | `operator` | 문자열 | `eq`, `ne`, `lt`, `le`, `gt`, `ge`, `contains`, `is_null` 중 하나다. |
| 조건 | `value` | 단일값 | — |
| 정렬 | `field` | 텍스트 | — |
| 정렬 | `descending` | 불리언 | — |

모든 필드는 필수다. 조건 값과 대상 열의 자료형·연산 의미가 맞는지는 N02-O.3에서 확인한다.

#### 가공 연산 객체

각 연산은 `operation`으로 종류를 지정하며, 해당 연산에 나열한 필드를 모두 포함한다.

| 연산 | `operation` 값 | 나머지 필드 | 자료형 | 형식 기준 |
| --- | --- | --- | --- | --- |
| 계산 | `calculate` | `method` | 문자열 | `difference`, `ratio`, `percentage`, `percent_change` 중 하나다. |
| 계산 | `calculate` | `before`, `after`, `output` | 텍스트 | — |
| 집계 | `aggregate` | `method` | 문자열 | `sum`, `mean`, `min`, `max`, `count` 중 하나다. |
| 집계 | `aggregate` | `field`, `output` | 텍스트 | — |
| 집계 | `aggregate` | `group_by` | 텍스트 배열 | 빈 배열을 허용한다. |
| 결합 | `join` | `right_result_id` | 문자열 | — |
| 결합 | `join` | `keys` | 텍스트 배열 | 1개 이상이다. |
| 결합 | `join` | `how` | 문자열 | `inner`, `left` 중 하나다. |
| 결합 | `join` | `fields` | 텍스트 이름 → 텍스트 이름의 객체 | 오른쪽 원본 열 이름을 결과 열 이름에 연결하며, 항목은 1개 이상이다. |
| 행 필터 | `filter` | `conditions` | 조건 객체 배열 | 위 조건 객체 정의를 따른다. |
| 자료형 변환 | `cast` | `field` | 텍스트 | — |
| 자료형 변환 | `cast` | `kind` | 문자열 | `string`, `integer`, `number` 중 하나다. |
| 정렬 | `sort` | `by` | 정렬 객체 배열 | 위 정렬 객체 정의를 따르며, 1개 이상이다. |

#### 시각화 입력 프로필

선택한 뷰에 연결된 프로필을 적용한다. 아래 매개변수는 모두 필수이며 JSON 문자열로 전달한다.

| 프로필 | 매개변수 이름 | 자료형 | 형식 기준 |
| --- | --- | --- | --- |
| 도시 단위 `monthly_city` | `p_city` | 문자열 | 도시 식별 문자열이다. |
| 도시 단위 `monthly_city` | `p_start`, `p_end` | 문자열 | `YYYY-MM-DD` 형식의 유효한 날짜다. |
| 상세 지역 `monthly_detail` | `p_detail_adm` | 문자열 | 행정동 표시 문자열이다. |
| 상세 지역 `monthly_detail` | `p_start`, `p_end` | 문자열 | `YYYY-MM-DD` 형식의 유효한 날짜다. |

| 프로필 | 필터 이름 | 자료형 | 형식 기준 |
| --- | --- | --- | --- |
| 도시 단위 `monthly_city` | `읍면동` | 텍스트 배열 | 필터는 생략할 수 있으며, 제공하면 값은 1개 이상이다. |
| 상세 지역 `monthly_detail` | — | — | 지정할 필터가 없다.<br>`filters`를 생략하거나 빈 객체로 반환한다. |

뷰와 프로필의 연결은 [등록 뷰의 입력 프로필](../../agent/tableau.md#뷰와-입력-프로필)에 따라 사례에 고정한다.
매개변수·필터의 이름과 자료형은 N-F.1에서 위 정의에 대조한다.
지역·기간·필터 값의 허용 범위·요청 일치는 N02-O.3에서 판정한다.
