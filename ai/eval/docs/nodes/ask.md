[노드 평가 개요·지표·합격 판정](README.md) · [공통 평가 기준](common.md)

## 평가 범위

사용자 정보 요청 노드(N05)가 반환한 질문이 필요한 정보를 빠짐없이 구체적으로 요청하는지 평가한다.

## 출력 형식

출력 형식은 [정형 평가 정의](ask.json)의 `output-format` 원칙을 따른다.

## 전용 검사

검사 정의의 단일 원본은 [정형 평가 정의](ask.json)다. 이관 내용은 [원본 Markdown 보관본](originals/ask.md)과 대조한다.
