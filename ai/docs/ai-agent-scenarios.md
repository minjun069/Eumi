# AI Agent 실행 시나리오

수정일: 2026-10-30.

실행 예시·시연 문구·산출물을 장면별로 정리한다. 아래 순서는 예상 흐름이며 고정된 절차가 아니다. 실제 실행은 공통 실행 흐름을 따르고 상황에 따라 단계를 추가하거나 생략한다.

지역·수치·날짜·출처는 실행 흐름을 설명하기 위한 가상 예시다. 모든 화면에 ‘시연용 예시 데이터’를 표시한다.

## 1. 장면 구성

| 장면 | 시작 | 담당 Agent | 산출물 |
| --- | --- | --- | --- |
| S1 기본 분석 해석 | 분석 완료 이벤트 | 데이터 분석 결과 해석 Agent | 해석문·비교표·근거 |
| S2 동별 비율 시각화 | 자연어 요청 | 사용자 요청 처리 Agent, 데이터 시각화 Agent | 차트·사용 데이터·표현 설정 |
| S3 선택 차트 설명 | 자연어 후속 요청 | 사용자 요청 처리 Agent, 데이터 분석 결과 해석 Agent | 통합 답변·기존 차트·근거 |

자연어 요청은 같은 대화창에서 받는다. 자동 실행에 가짜 사용자 발화를 넣지 않는다. 상태 문구는 실제 조회·계산·렌더링·작업 진행 판단에 맞춰 표시한다. 진행 상태 안내와 실제 산출물을 포함한 중간 응답을 구분한다.

## 2. S1 기본 분석 해석

### 2.1 입력과 처리

사전 조건: 조회할 분석 결과와 D1·D2가 등록되어 있다. 시스템은 분석 완료 이벤트로 goal에 목적·분석 대상·기간을 서술하고 constraints와 시스템 지침 messages를 구성한다. 실제 자료 버전은 조회 결과에서 확보한다. 분석 완료 이벤트 후 해석을 생성하고, [연동 API 초안 §3.4](ai-runtime-api-20261029.md#34-해석-결과)의 조건에 따라 게시하면 담당자는 A동 분석 화면에서 확인한다.

| 순서 | 처리 | 화면 상태·문구 |
| --- | --- | --- |
| 1 | 이벤트 입력 검증 후 작업 목적 파악을 생략하고 작업 선택 및 실행에서 분석 결과·지표 정의·비교 기준·실제 버전 조회. 호출 조건 충족 여부 검증 | 분석 자료 확인 중 — 분석 결과와 지표 정의를 확인하고 있어요. |
| 2 | 작업 진행 판단에서 부족한 비교 정보·이유 기록. 작업 선택 및 실행에서 구체적인 조회·가공 선택, 실행·검증·필요한 재시도 | 비교 자료 확인 중 — 인접 지역과 전년도 같은 기간을 비교하고 있어요. |
| 3 | 작업 진행 판단에서 작성 가능 여부 기록 후 응답 작성에서 주요 신호·비교 설명·근거·한계와 비교표를 response로 구성 | 해석 작성 중 — 확보한 비교 결과를 바탕으로 변화와 한계를 설명하고 있어요. |
| 4 | 해석 결과를 게시 담당에 전달. 게시 조건에 따라 저장·게시 | 분석 해석 준비 완료 — 아래 해석·비교표·출처 표시 |

해석할 자료가 없으면 사유를 반환하고 일부만 설명할 수 있으면 범위를 표시한다. 자연어 요청으로 실행한 해석은 호출자에게 반환하며 대시보드 해석을 자동 교체하지 않는다. 이미 게시된 해석은 바로 표시하고, 화면 진입만으로 분석을 실행하거나 로딩을 다시 연출하지 않는다.

### 2.2 산출물: A동 활동지수 감소 해석

A동의 2026년 9월 활동지수는 108로, 8월의 120보다 10.0% 감소했습니다. 인접 지역과 전년도 같은 기간에도 감소가 나타나, 이 변화만으로 A동의 사회적 고립 위험이 증가했다고 단정하기는 어렵습니다.

**지표의 의미**

각 동의 2025년 1월 관측 활동량을 100으로 환산한 지수입니다. A동의 108은 A동 기준 시점보다 8% 높은 수준입니다. 고립 위험 점수가 아니며, 서로 다른 동의 지수 수준을 활동량의 절대 크기로 비교하지 않습니다.

**비교 근거**

| 지역 | 2026년 8월 | 2026년 9월 | 변화율 | 2025년 8월 | 2025년 9월 | 변화율 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A동 | 120 | 108 | -10.0% | 110 | 99 | -10.0% |
| B동 | 100 | 92 | -8.0% | 100 | 92 | -8.0% |
| C동 | 80 | 72 | -10.0% | 90 | 81 | -10.0% |

변화율은 각 연도의 `(9월 지수 - 8월 지수) ÷ 8월 지수 × 100`입니다. 전년 동월 대비 변화율과 구분합니다.

**해석 한계**

현재 비교 결과는 A동에만 나타난 변화라는 설명을 뒷받침하지 않습니다. 계절적 변화나 여러 지역에 함께 작용한 요인도 가능한 설명입니다. 한 해의 비교로 계절성이 원인이라고 확정할 수 없습니다. 해석은 관측된 지역·집단 단위의 변화에 한정합니다.

출처: 가상 자료 D1·D2. 같은 정의·집계 기준으로 비교할 수 있다는 예시 조건을 적용했습니다.

### 2.3 노드별 State 반영 예시

아래는 노드 처리가 끝난 시점의 기록이다. 데이터·버전 값은 시연용이며 실제 호출 결과에서 확보한다.

| 위치 | request | messages | results | response | execution |
| --- | --- | --- | --- | --- | --- |
| 이벤트 초기화 | 목적·분석 ID·A동·2026년 9월을 goal에 서술, 조건 설정 | 시스템 지침 | [] | null | queued, 배포 version, 사용량 0 |
| 작업 선택 및 실행: 기본 조회 | 유지 | 유지 | 선택 이유, A동 120→108·지표 정의·출처·실제 버전의 output, 검증 기록 | progress: 분석 자료 확인 중 | running, 호출 사용량 증가 |
| 작업 진행 판단: 비교 부족 | 유지 | 유지 | 인접 지역·전년도 비교 자료가 부족하다는 decision·reason 추가 | progress: 비교 자료 확인 중 | running |
| 작업 선택 및 실행: 비교·계산 | 유지 | 유지 | B·C동·전년도 조회, A -10%·B -8%·C -10% 계산, 검증·재시도 기록 | progress: 비교 자료 확인 중 | running, 호출 사용량 증가 |
| 작업 진행 판단: 작성 가능 | 유지 | 유지 | 확보한 근거로 설명 가능하다는 decision·reason 추가 | progress: 해석 작성 중 | running |
| 응답 작성 | 유지 | 유지 | 해석·비교표 작성 이력 | final, 해석·출처·한계는 content, 비교표는 artifacts | 반환·종료 시 completed |
| 게시 담당 | 유지 | 유지 | Agent 내부 이력 유지 | 생성 응답 유지 | completed 유지. 게시 성공과 구분 |

별도 info·subject·pending·요청 수정 번호는 사용하지 않는다. results는 내부 이력이며 response만 공개 내용으로 구성한다. 구체적인 쓰기 책임은 [State §2](ieumi-agent-state.md#2-노드별-쓰기-범위)를 따른다.

## 3. S2 동별 비율 시각화

### 3.1 입력과 처리

사전 조건: 화면의 비교 범위는 A~E동이며 D3의 지표 정의·기준일이 등록되어 있다.

사용자 입력: “2026년 9월 말 기준으로 동별 고령 1인 가구 비율을 높은 순서대로 그래프로 보여줘.”

시작 응답: “선택된 5개 동의 고령 1인 가구 비율을 확인해 높은 순서대로 보여드리겠습니다.”

| 순서 | 처리 | 화면 상태·문구 |
| --- | --- | --- |
| 1 | 작업 목적 파악 후 작업 선택 및 실행에서 데이터·단위·기간·비교 기준 조회 | 데이터 조회 중 — 같은 기준일의 동별 가구 자료를 확인하고 있어요. |
| 2 | 작업 진행 판단에서 필요한 비율·정렬 결과가 부족함을 기록. 작업 선택 및 실행에서 계산·정렬 도구 선택·호출·검증 | 비율 계산·정렬 중 — 전체 가구 중 고령 1인 가구 비율을 계산하고 있어요. |
| 3 | 작업 선택 및 실행에서 표현 설정을 정해 렌더링 도구 호출. 생성값·정렬·표현 조건을 검증하고 필요한 보완 수행 | 그래프 생성 중 — 비율을 비교할 가로 막대그래프를 만들고 있어요. |
| 4 | 작업 진행 판단에서 실제 시각화와 요청한 정렬·표현·출처가 확보됐는지 확인하고 보완 필요 여부 결정 | 그래프 확인 중 — 요청한 비교를 보여줄 준비가 됐는지 확인하고 있어요. |
| 5 | 응답 작성에서 시각화·사용 자료·설정·주의사항 구성. 요청 처리 Agent가 공개 응답을 작성하고 서버 전달 후 프론트가 표시 | 시각화 완료 — 아래 차트·데이터·설정 표시 |

원자료와 다르면 데이터·표현 설정을 보완하고 다시 렌더링한다. 명세만 생성한 상태는 완료로 처리하지 않으며 결측을 0으로 표시하지 않는다.

### 3.2 산출물: 동별 고령 1인 가구 비율

최종 응답: “C동 14.4%, A동 12.5%, E동 11.2%, B동 9.6%, D동 7.1% 순입니다. 가구 구성 비율의 순위이며 고립 위험 순위는 아닙니다.”

기준일: 2026-09-30. 전체 가구 중 65세 이상 1인 가구가 차지하는 비율입니다.

![동별 고령 1인 가구 비율 가상 예시](assets/agent-output-examples/elderly-single-households.png)

| 순위 | 지역 | 65세 이상 1인 가구 수 | 전체 가구 수 | 비율 |
| --- | --- | ---: | ---: | ---: |
| 1 | C동 | 1,728 | 12,000 | 14.4% |
| 2 | A동 | 1,250 | 10,000 | 12.5% |
| 3 | E동 | 1,232 | 11,000 | 11.2% |
| 4 | B동 | 768 | 8,000 | 9.6% |
| 5 | D동 | 639 | 9,000 | 7.1% |

계산식: `65세 이상 1인 가구 수 ÷ 전체 가구 수 × 100`. 고령자 가구만을 분모로 사용하지 않습니다. 이 순위는 가구 구성 비율이며 사회적 고립 위험 순위가 아닙니다.

| 설정 | 내용 |
| --- | --- |
| 표현·정렬 | 가로 막대그래프, 비율 내림차순 |
| 축 | 가로 0~20%, 세로 지역명 5개 |
| 수치 | 소수점 첫째 자리 표시 |
| 색상 | 동일 파란색. 위험 등급을 나타내지 않음 |
| 자료 | [사용 데이터 JSON](assets/agent-output-examples/visualization-data.json), 가상 자료 D3 |

5개 동 모두 같은 기준일·지표 정의를 사용하며 결측값은 없습니다.

## 4. S3 선택 차트 설명

### 4.1 입력과 처리

사전 조건: S2의 차트·D3·기준일을 선택 대상으로 유지한다.

사용자 입력: “이 그래프에서 A동은 어떻게 읽으면 돼? 고립 위험이 두 번째로 높다는 뜻이야?”

| 순서 | 처리 | 화면 상태·문구 |
| --- | --- | --- |
| 1 | 작업 목적 파악에서 현재 화면·선택 차트·관련 이력으로 대상 특정 | 선택한 그래프 확인 중 — 현재 그래프의 자료와 지표 정의를 확인하고 있어요. |
| 2 | 작업 선택 및 실행에서 해석 Agent로 비율·비교 기준에 대한 설명 요청 | 설명 검토 중 — A동의 비율과 해석할 수 있는 범위를 확인하고 있어요. |
| 3 | 작업 진행 판단에서 추가 설명에 필요한 결과 확보 여부 확인 후 응답 작성에서 해석과 기존 차트·근거 통합 | 설명 완료 — 아래 통합 답변과 S2 차트·근거 연결 |

### 4.2 산출물: 통합 답변

> A동은 전체 10,000가구 중 65세 이상 1인 가구가 1,250가구로, 비율은 12.5%입니다. 표시된 5개 동 중 두 번째로 높습니다.
>
> 이 순위는 가구 구성 비율입니다. 사회적 고립 위험이 두 번째로 높다는 뜻은 아닙니다. 방문 지역을 판단하려면 다른 분석 지표와 현장 정보를 함께 검토해야 합니다.

통합 응답에는 S2의 선택 차트·사용 데이터·근거를 연결한다. 새 시각화가 필요하지 않으면 기존 차트를 유지한다. S1의 활동지수와 S2의 가구 비율은 서로 다른 지표이며 같은 값처럼 설명하지 않는다.

### 4.3 요청별 도구·Agent 호출

| 요청 | 선택할 작업 |
| --- | --- |
| “이 지표가 줄어든 이유를 설명해줘.” | 해석 Agent로 관측 변화·비교 근거·설명 가능한 범위 확인 |
| “동별 고령 1인 가구 비율을 그래프로 보여줘.” | 시각화 Agent로 조회·정렬·렌더링 후 결과 제공 |
| “A동 활동지수의 변화를 그래프로 보여주고 설명해줘.” | 같은 자료·버전으로 시각화와 해석을 요청하고 통합 |

현재 화면·선택 대상·관련 이력으로 요청을 특정한다. 확인할 수 있는 정보를 반복해서 묻지 않는다. 대상이 모호하거나 사용자만 제공할 수 있는 핵심 정보가 부족하면 질문한다. 범위 밖 요청은 지원 범위를 안내한다.

## 5. 예외 표시

| 상황 | 화면 문구 | 처리 |
| --- | --- | --- |
| 대상 모호 | “어떤 지역과 기간을 비교할까요?” | 질문·State·위치 저장 후 처리 작업 종료, waiting_input 유지. 같은 실행 ID로 답변을 받아 복원·재개 |
| 자료 없음 | “현재 조회 범위에 해당 자료가 없습니다.” | 조회 범위와 미확인 사항 표시 |
| 조회 실패 | “자료를 불러오지 못했습니다.” | 자료 없음과 구분 |
| 지표 정의 누락 | “지표 뜻을 확인할 자료가 필요합니다.” | 설명 가능한 범위만 제공 |
| 차트 불일치 | “그래프의 표시값을 수정하고 있습니다.” | 작업 선택 및 실행에서 불일치 검증·보완 이력 기록. 작업 진행 판단 후 응답 작성에서 해당 차트를 교체·제외 |
| 취소 | “요청을 중단했습니다.” | 후속 실행 중단 |

## 6. 가상 자료

| 자료 | 정의·용도 |

| D1 월간 활동지수 비교 자료 | 2025·2026년 8·9월 A·B·C동의 관측 지수 |

화면에는 ‘시연용 예시 데이터’를 표시한다. D1~D3은 실제 기관 URL이나 검증된 출처를 대신하지 않는다.

이 문서는 시연 콘텐츠이며 영상 촬영이나 실제 데이터 연동 완료를 뜻하지 않는다.

## 7. S2·S3의 기록·공개 적용

S2의 조회·비율 계산·정렬·렌더링·검증은 각각 results에 기록한다. 실제 시각화가 준비되면 응답 작성에서 차트·사용 데이터·설정은 response.artifacts에, 설명·출처·한계는 content 또는 해당 산출물에 포함한다.

S3는 관련 대화와 선택 차트를 읽어 goal·constraints를 구체화한다. 쓰기 범위가 읽기 범위를 제한하는 것은 아니다. 해석 Agent 호출 이유·결과와 작업 진행 판단은 results에 남기고, 응답 작성에서 기존 S2 차트를 유지한 response를 구성한다. 내부 sources·issues·result_refs 필드는 추가하지 않는다.
