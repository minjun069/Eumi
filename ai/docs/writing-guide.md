# AI 문서 작성 지침

수정일: 2026-11-09. 런타임·에이전트 명세와 설치·실행·검증 안내의 작성·수정·검토에 적용한다. 공통 규칙과 지침 유지 관리는 [프로젝트 지침](../../../AGENTS.md)을 따른다.

## 1. 작성 원칙

- [문서 목록](README.md)의 현행 명세와 최신 사용자 수정본을 기준으로 한다.
- 평가 문서는 [평가 문서 작성 지침](../eval/docs/writing-guide.md)을 함께 따른다.
- 확정된 내용과 제안·예시·미확정 사항을 구분한다. 근거 없는 용도·효과·수치를 넣지 않으며, 미확정 사항에 따라 달라지는 내용도 확정하지 않는다.
- 기능이나 개념은 무엇이며 왜 필요한지 먼저 설명한 뒤 세부 내용을 쓴다. 명칭이나 항목을 나열하는 것으로 설명을 대신하지 않는다.
- 동작을 설명할 때는 누가, 어떤 조건에서, 무엇을 하며, 어떤 결과가 생기는지 쓴다. ‘처리·반영·정책’ 같은 포괄어만으로 설명하지 않는다.
- 제목과 문장은 짧게 쓰고, 한 문단에서는 하나의 주제를 설명한다. 같은 설명의 반복, 편집 과정, 이해나 판단에 필요하지 않은 단서는 삭제한다.
- 용어·약어는 처음 사용할 때 뜻을 설명하고, 혼동하기 쉬운 개념은 차이를 밝힌다. 같은 대상에는 일관된 명칭을 사용하며 해당 명세의 정의를 따른다.
- 본문·표·그림에는 한글명을 사용하고, 영어명은 코드 식별자가 필요한 곳에만 쓴다.

## 2. 구조와 서식

- 문서 위치와 읽는 순서는 [문서 목록](README.md)을 따른다.
- 파일명은 소문자 영문·하이픈을 사용하고, 폴더와 중복되는 접두어나 날짜는 넣지 않는다. `README.md`와 `AGENTS.md`는 관례적 이름을 유지한다. 
- 수정일·상태는 본문에서, 이전 판은 Git 기록에서 관리한다.
- 같은 단계의 항목은 같은 기준으로 분류한다. 
- 반복해서 설명하는 대상은 항목과 설명 순서를 맞추고, 공통 항목과 대상별 항목을 구분한다. 해당 없는 항목은 생략한다.
- 항목별 명세·비교·분기는 Markdown 표로 정리한다. 한 열에는 하나의 속성을 두고, 서로 독립된 속성을 구분자나 괄호로 한 칸에 합치지 않는다.
- 같은 명세는 한 곳에서 관리하고 다른 문서에서는 링크로 참조한다.
- 그림은 관련 설명 바로 아래에 원본 위치와 함께 두고, 가로·세로 비율을 유지한다.

## 3. 수정과 검수

기존 문서를 수정할 때는 요청한 변경과 그에 따른 관련 부분을 수정한다. 
지적된 사례와 같은 문제가 대상 문서 전체에 있는지 확인하고, 관련 설명·표·그림·예시·참조를 함께 고친다. 
수정 범위 밖의 내용·명칭·양식은 임의로 바꾸지 않는다.

분량을 줄일 때는 항목 자체가 필요한지도 검토하되, 필수 조건·예외·입출력 계약은 보존한다. 
다음 항목을 확인한 뒤 완료를 보고한다.

| 검수     | 확인할 내용                                                                        |
| ------ | ----------------------------------------------------------------------------- |
| 내용 대조  | 수정한 문서 전체를 다시 읽고 관련 명세·표·그림·예시 사이에 모순이나 누락이 없는지 확인. 조건·예외·수치·단위·집계 기준도 함께 대조  |
| 상태 구분  | 요구사항으로 확정한 내용, 현재 구현한 내용, 검증하지 않은 내용, 결정하지 않은 내용을 구분했는지 확인                    |
| 명세 불일치 | 다른 문서와 요구사항이나 입출력 계약이 어긋나면 근거와 영향을 해당 명세에 기록. 불일치를 해소하기 위해 새 계약을 임의로 확정하지 않음  |
| 참조 검사  | 문서 목록, 이동 전 경로 참조, 로컬 링크·그림·제목 앵커를 검사. 이동·이름 변경 시 들어오는 참조와 문서 내부 상대 경로를 함께 갱신 |
| 결과 보고  | 검수한 범위·결과·남은 불일치를 보고. 링크 검사 통과를 내용의 정확성이나 실제 연동 성공으로 대신하지 않음                  |

참조 검사는 `Eumi/ai/`에서 `python scripts/check_docs.py`로 실행한다. 
자동 검사와 별도로 내용을 읽고 의미가 일치하는지 확인한다. 
페이지로 출력하는 산출물은 페이지 나눔·표·그림·잘림도 확인한다.
