# AI Agent MVP 범위

수정일: 2026-10-30.

## 1. 문제 정의

사회복지사의 지역 탐색을 지원한다. 넓은 지역에서 방문 범위를 좁힐 근거가 부족하고, 지역·집단별 특성을 함께 파악하기 어렵다.

AI는 분석 결과의 의미와 비교 근거를 설명한다. 담당자는 제보·의뢰와 현장 정보를 함께 검토해 방문 지역과 우선순위를 결정한다.

## 2. 지원 범위

| 구성 | 역할 |
| --- | --- |
| 데이터 분석 결과 해석 Agent | 분석 결과·지표 정의를 조회하고 주요 신호·비교 결과·해석 한계 설명 |
| 데이터 시각화 Agent | 목적에 맞는 차트·표·지도 선택, 가공·렌더링, 표현 결과 확인 |
| 사용자 요청 처리 Agent | 작업 목적 파악, 필요한 Agent·도구 호출, 응답 작성에서 중간 결과 제공·최종 결과 통합 |

## 3. 제공 방식

| 구분 | 제공 내용 |
| --- | --- |
| 기본 화면 | 분석 완료 후 생성한 해석을 해당 분석 결과와 함께 표시. 게시 조건은 연동 API 명세에 정의 |
| 자연어 요청 | 선택한 지역·지표·차트에 대한 추가 설명, 비교, 시각화. 진행 중 제공 가능한 결과를 먼저 표시하고 최종 응답으로 갱신 |
| 산출물 | 근거·한계를 포함한 설명문, 실제 차트·표·지도, 연결된 통합 답변 |

해석 생성은 분석 완료 이벤트를 기준으로 한다. 사용자가 매번 질문해야 기본 해석이 생성되는 구조로 만들지 않는다. 실행 조건은 [실행 흐름](ieumi-agent-workflow-design.md)에서 관리한다.

## 4. 판단 범위

- 해석을 작성할 때는 관측된 지역·집단·기간의 변화와 비교 근거에 한정한다. 관측 사실과 가능한 설명을 구분한다. 적용 책임은 [기능 명세](ieumi-agent-components.md)의 해석 작성·결과 통합 역할에 따른다.
- 분석 모델은 수치 분석을 담당하고 Agent는 결과를 조회·가공·해석한다. 위험지수 산출 모델을 Agent가 임의로 변경하지 않는다.
- 자료에서 확인된 공간·시간 단위와 비교 가능한 범위 안에서 설명한다.
- 허용된 자료만 사용한다. 없는 수치·출처·확인 결과를 만들어 채우지 않는다.
