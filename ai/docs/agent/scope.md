# AI 에이전트 초기 제공 범위

수정일: 2026-11-12.

## 1. 문제 정의

사회복지사의 지역 탐색을 지원한다. 넓은 지역에서 방문 범위를 좁힐 근거가 부족하고, 지역·집단별 특성을 함께 파악하기 어렵다.

AI는 분석 결과의 의미와 비교 근거를 설명한다. 담당자는 제보·의뢰와 현장 정보를 함께 검토해 방문 지역과 우선순위를 결정한다.

## 2. 지원 범위

| 구성 | 역할 |
| --- | --- |
| 데이터 분석 결과 해석 에이전트 | 분석 결과·지표 정의를 조회하고 주요 신호·비교 결과·해석 한계 설명 |
| 데이터 시각화 에이전트 | 목적에 맞는 게시된 Tableau 뷰와 표시 조건을 선택하고 등록 설정에 맞는지 검사. 실제 화면 표시와 적용값 확인은 프론트가 수행 |
| 사용자 요청 처리 에이전트 | 작업 목적 파악, 정보 충분성·필요한 정보 판단, 판단에 따른 에이전트·도구 호출, 최종 답변·산출물 통합 또는 필요한 정보 질문 |
| 보고서 시각화 선정 에이전트 | 필요한 근거를 조회·가공하고 상세 뷰와 설명 가능한 범위를 선정 |
| 보고서 시각화 설명 에이전트 | 선정한 뷰·근거·설명 범위를 받아 자료를 보완하고 뷰별 설명 작성·검토 |
| 보고서 퀵 인사이트 에이전트 | 검토를 통과한 설명과 근거의 범위에서 핵심 내용을 요약·검토 |

보고서 생성 흐름은 세 보고서 에이전트를 순서대로 실행하고 여러 동의 실행·저장·완료 알림을 관리한다. 각 역할의 입력·산출물과 앞 단계 변경 금지, 추가 조회 범위는 [보고서 생성](report.md)에서 정의한다.

## 3. 제공 방식

| 구분 | 제공 내용 |
| --- | --- |
| 기본 화면 | 분석 완료 후 생성한 해석을 해당 분석 결과와 함께 표시. 게시 조건은 연동 API 명세에 정의 |
| 자연어 요청 | 선택한 지역·지표·차트에 대한 추가 설명, 비교, 시각화. 실행 중 단계 시작 안내를 표시하고, 종료 시 답변·산출물 또는 필요한 질문 제공 |
| 산출물 | 근거·한계를 포함한 설명문, 차트·표·지도를 표시할 산출물, 연결된 통합 답변 |

해석 생성은 분석 완료 이벤트를 기준으로 한다. 사용자가 매번 질문해야 기본 해석이 생성되는 구조로 만들지 않는다. 실행 조건은 [실행 흐름](workflow.md), 시각화의 지원 범위와 화면 표시 계약은 [Tableau 시각화](tableau.md)에서 관리한다.

## 4. 판단 범위

- 해석을 작성할 때는 관측된 지역·집단·기간의 변화와 비교 근거에 한정한다. 관측 사실과 가능한 설명을 구분한다. 적용 책임은 [기능 명세](components.md)의 해석 작성·결과 통합 역할에 따른다.
- 에이전트는 제공된 분석 결과를 조회·가공·해석한다.
- 자료에서 확인된 공간·시간 단위와 비교 가능한 범위 안에서 설명한다.
- 허용된 자료만 사용한다. 없는 수치·출처·확인 결과를 만들어 채우지 않는다.
