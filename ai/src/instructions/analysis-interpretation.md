# 분석 결과 해석

지침 ID: `analysis-interpretation`, 버전: `1`, 시행일: 2026-11-09.

분석 결과를 해석·통합·검토할 때 적용하는 내용 기준이다.
수행할 작업·도구·출력 형식·종료 조건은 현재 역할과 단계의 지침을 따른다.

## 결과의 목적

확인된 수치의 관계를 설명해 복지 담당자가 어느 지역·집단·활동 변화에
주목하고 무엇을 확인할지 이해하도록 돕는다. 수치 나열이나 일반적인 주의문에
그치지 않고, 근거가 지지하는 의미를 제시한다.

## 관측과 비교

- 이번 단계에 허용된 근거 안에서 규모·변화 방향·차이가 집중된 축과 유지된 축을
  함께 본다. 확보된 원값·계산된 증감·변화율·이전 기간의 범위를 연결하며,
  큰 변화율만으로 중요도를 정하거나 임의의 공통 임계값을 만들지 않는다.
- 비교 가능한 지역·집단·기간 안에서 설명한다. 서로 다른 집계의 동시 변화를
  같은 사람이나 교차 집단의 변화로 합치지 않는다.
- 행동 이상 점수는 학습 기준 행동과의 차이다. 상승·하락만으로 활동 위축이나
  고립 악화·개선을 판단하지 않는다. 배경 여건·실제 활동·점수는 서로 다른
  근거이며, 활동 인구에는 방문자가 포함될 수 있어 주민의 관계 상태와 같지 않다.

## 의미와 지역 맥락

- 관측 패턴에서 활동의 집중·축소·확장·유지와 그 범위를 설명한다. 활동 기회나
  참여 경로에 관한 설명은 가능한 해석으로 제시하고, 확인된 원인·효과와 구분한다.
- 지역 맥락은 확보된 자료의 출처·시점·공간 범위 안에서 해석을 구체화하는 데 쓴다.
  지역 소개를 특정 구역의 시설·이용자 특성이나 분석기간의 운영 사실로 대입하지 않는다.
- 지역 맥락이나 현장 확인 자료가 없어도 수치 기반 해석을 작성한다. 근거가 없는
  부분만 한정하고, 자료가 지지하는 유지·안정도 결과로 설명한다.

## 작성과 검토

- 핵심 관측과 그 의미를 연결하고, 판단에 영향을 주는 다른 가능성이나 추가 확인
  대상을 필요한 경우 덧붙인다. 후속 확인 제안을 현재 실행의 필수 자료로 요구하지 않는다.
- 방문·지원의 최종 판단은 담당자에게 남긴다. 사례의 결론·차트 조합·문장 순서를
  고정하지 않으며, 허용된 분량 안에서 해당 결과에 중요한 내용만 설명한다.
- 검토는 주장과 근거의 연결, 점수·활동·관계 상태의 구분, 비교·맥락의 적용 범위를
  확인한다. 확인되지 않은 원인 단정은 수정하되, 근거에 맞게 한정한 해석을
  현장 검증 전이라는 이유만으로 거절하지 않는다.
