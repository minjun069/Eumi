## 2. 사용자 결정·계약·DTO

사용자는 이름 사전을 추가하지 않고 마스킹을 유지하며, 이름 단어 수·문장부호·질문 경계로 가림 범위를 제한하고 질문 보존 회귀 검사를 추가하도록 결정했다. 요청·응답 DTO·오류 코드·상태 코드 변경은 없다.

- 이름 표지는 최대 세 단어를 읽는다. 붙여 쓴 한글 이름, 띄어 쓴 이름, 호칭·질문 시작 표현을 구분해 이름 뒤의 질문을 남긴다. 영어 이름과 문장부호도 처리한다.
- 주소는 쉼표 뒤 상세 주소까지 가리되, 문장부호나 `이 지역`·`위험도는`·`알려` 같은 질문 경계가 나오면 뒤 문장을 보존한다. 개인정보가 잘려 남는 것을 피하려고 주소에 임의 글자 수 상한을 두지는 않았다.
- 계좌·카드 표지는 은행명과 숫자 값 뒤의 질문을 남긴다. 전화·주민번호·이메일 가림은 계속 적용한다.
- 표지 앞에 문자·숫자·밑줄 경계를 적용한다. `이메일주소` 안의 `주소`를 별도 표지로 처리하지 않는다.
- 치환 뒤의 `$`·역슬래시가 정규식 치환 문법으로 해석되지 않게 처리한다.

합성 입력의 기대 결과:

| 입력 | 저장되는 질문 |
|---|---|
| `이름: 홍길동 어르신의 위험도는?` | `이름: [이름] 어르신의 위험도는?` |
| `주소: 서울 강남구 역삼동, 이 지역 위험도 알려줘` | `주소: [주소], 이 지역 위험도 알려줘` |
| `이메일주소: person@example.test 위험도는?` | `이메일주소: [이메일] 위험도는?` |

이 처리는 사전·NER가 아닌 규칙 기반이다. 표지가 없거나 이름·주소와 질문의 경계가 모호한 자유서술 전체를 판별하지 않는다. 주소에 인식 가능한 질문 경계가 없으면 필드 끝까지 가릴 수 있고, 세 단어를 넘는 이름 등은 규칙의 한계가 있다. 실제 AI 전환 전 개인정보 계약의 허용 범위 확인은 계속 필요하다.

## 3. 권한·잠금·진단

소유권·제한 세션·트랜잭션·잠금·재시도 정책은 그대로다. writer는 KEY SHARE와 DB 끝 행 UNIQUE를 사용하고 40P01은 새 트랜잭션에서 한 번만 재시도한다.

- 비동기 HTTP 실패는 ExecutionException·CompletionException 포장만 벗겨 실제 원인 클래스 이름을 남긴다. 연결 거부와 HTTP 시간 초과를 구분한다. 예외 메시지·스택·본문은 기록하지 않는다.
- BE가 끝 행을 실제로 저장했을 때만 conversationId·questionId·작업·상태를 WARN으로 남긴다. 작업은 `start-failure`, `execution-timeout`, `cancel-fallback`이다. 이미 끝난 질문에 대한 중복 무시를 새 보완 행 저장으로 기록하지 않는다.
- 질문 원문·응답 원문·쿠키·세션 값은 진단에 넣지 않는다.

## 5. 인계·남은 것

- 운영 배포는 Jenkinsfile 기준 master push(develop → master MR 병합) 때다. develop 병합만으로 배포되지 않는다.
- **master 배포 전 순서:** 서버 `.env.config`에 `EUMI_AI_MODE=fake` 설정 → 운영 Compose backend environment에 필수 변수 전달 및 example 반영 → 컨테이너 전달 확인 → master 배포. 서버의 실제 비밀 설정은 읽거나 수정하지 않았다. 저장소의 infra·Jenkinsfile은 인계를 위해 읽기로 확인했으며 수정하지 않았다.
- 필수 전달 예: `EUMI_AI_MODE: ${EUMI_AI_MODE:?.env.config에 EUMI_AI_MODE가 필요합니다}`. 서버 값이 없는데 Compose 보간부터 반영하면 Compose 해석이 실패해 web 배포도 함께 실패할 수 있다. 상세 인계는 [1차 후속 문서 5절](2026-11-03_review-follow-up.md#5-인프라-인계남은-것)을 참고한다.
- HTTP 전환은 `EUMI_AI_MODE=http`, `AI_BASE_URL`, 실행 제한·BE 여유·무응답 판정·취소 대기의 합의값 전달이 필요하다. 현재 시간 값 미합의와 메모리 재요청·취소 상태의 재시작 한계는 해결된 것으로 취급하지 않는다.
