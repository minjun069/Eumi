# 프로토타입 기능 상세 계약

API가 없는 로컬 동작까지 포함한 인수 기준이다. 등록은 구현 완료가 아니다. 업무 API는 OpenAPI, DB는 eumi V1~V6, 임베딩은 대시보드_구현_확정안.md(워크북 eumi_tableau_main_dashboard_v_master)를 기준으로 한다.

## 공통과 계정

메뉴·프로필 복원·로그아웃과 임시 암호 제한은 브라우저/서버에서 함께 적용한다. 이메일 저장은 동의에 따라 localStorage에 이메일만 보관한다. 비밀번호 보기/숨기기·확인 입력은 로컬 동작이다. 기관/이메일 변경 시 인증 상태를 비운다. 무도메인 기관 가입은 DB NOT NULL 기준으로 지원하지 않는다. 메일 발송부터 탈퇴 포함 기존 이메일을 거절한다. 구암호 무효·유효 임시 암호 재발급 금지 안내는 데모와 다르게 표시한다.

## 검색과 화면 이동

사례자는 관할 시군구, 자원은 전체 지역이 기본이다. 검색/적용 버튼이 입력을 확정하고 초기화는 입력만 되돌린다. 정렬/페이지/지표는 즉시 적용한다. 조건 변경 시 page=1, 상세 복귀·뒤로·새로고침에는 적용 URL을 복원한다. 단축 URL 키를 API DTO 이름으로 변환하고 null·빈 선택값은 query에서 생략한다.

자원은 진행 우선→선택 열/방향→종료일asc→IDasc, 사례자 최근 기록일null은 양방향 뒤이며 날짜 검색에서 제외한다. 빈 목록은 totalPages=0·page=1·items=[]다. 0/0 페이지를 표시하지 않는다. 자원4종·사례자6종 정렬을 보존한다.

listSearch/fromDetail/fromMy/recommendedFor는 navigation state로 HTTP에 넣지 않는다. 내 자원에서 온 상세는 마이페이지로 복귀하고 현재 추천에서 온 상세는 사례자 안내/복귀 링크를 보인다. 저장 대화에서 온 추천에는 사례자 이름 안내를 붙이지 않는다.

## 입력·상담·자원

변경된 사례자/자원/내 정보/상담 입력은 메뉴·취소·뒤로·창 닫기·로그아웃에서 미저장 확인을 띄우고 실패 시 보존한다. 저장 성공 후 가드를 해제한다. 새로고침·탭 종료 경고는 프로토타입에 없으며 추가 보장으로 간주하지 않는다.

중복은 같은 기관의 본인 담당 사례자만 검사하고 자신은 제외한다. 다른 직원 전용 사례자의 존재·관리번호·이름은 노출하지 않는다. 이름/생일 변경 때 재검사하고 그래도 저장할 수 있다. 본인 담당 제외는 확인 후 목록으로 간다. 동일 기관 활성 담당 최소1, 등록자는 자동 추가한다. 번호는 등록 후 고정·최고 삭제 후 재사용 가능·9999 서비스 한도다.

상담은 보기/등록/수정 공유 모달, 기타20자·목적200·내용20000 조건, 최초 기록자 보존, 공동 담당 수정/삭제를 지원한다. CRUD 뒤 상담 목록/상세와 사례자 최근 기록일을 갱신한다. 사례자 삭제 창에는 상담/연결도 삭제됨을 안내한다.

자원은 editable과 서버 권한 재검증, 자동 종료와 manualStatus 구분, 참여자>정원 안내와 저장 허용, 담당자 변경 전 권한 상실 확인을 제공한다. 자원 org_id 물리 컬럼은 없고 manager_member_id→member.org_id로 도출한다. 같은 기관 인계로 기관을 유지한다. 원 등록기관 불변 이력이 추가 요구되면 현재 ERD에 저장 근거가 없어 별도 설계가 필요하다.

## PDF

PDF1개·20MiB를 실제 multipart로 보내며413/415/422/503과 부분 추출을 구분한다. 기존값 덮어쓰기 확인·못 찾은 필수 항목 안내·AI 입력 배지·직접 수정 시 배지 해제를 제공한다. 담당자/상태/참여자는 추출하지 않는다. 추출이 자동 등록을 수행하지 않고 원문은 영구 저장하지 않는다.

## 대시보드

①지도·②단계 분포·③배경 분포·④첫 월 대비 행동 지수·⑤전월 변화·⑥100m 격자를 등록한다. ①③⑤·읍면동 요약/보고서/격자는 종료 월, ②④는 기간을 사용한다. ⑤는 기간 밖 직전 달도 비교하고 그 달 행이 없으면 비교 불가다. ③ 상위20%=1분위는 등급5 최고 위험과 다르다.

DB는 bg/bh를 도시 내1~5, risk_grade를 종합 단계라고 설명하지만 실제 산식이 저장소에 없다. 데모 고정 STAGE_CUTOFFS를 복제하지 않는다. 매월 시군구5분위로 정의하면②의 개수가 거의 고정되므로 분석 담당이 의미를 확정한다. 기존 읍면동 '행동 이상 기준' 배지는 behavior.stage다. riskGrade를 표시하려면 별도 '종합 위험'으로 구분한다.

anomaly_score는 격자3단계가 아니다. 낮음/중간/높음 경계·null 범례, gx/gy 좌표계/단위·geom 형식/SRID·100m 폴리곤·경계 격자 귀속은 DE1 정의 대상이다. null을 낮음으로 채우거나 합성 격자를 실제로 표시하지 않는다. ①②③⑤는 워크북 게시본에 연결했고 ④·⑥은 미게시다.

결과 없음404와 보고서 준비 중null을 구별한다. 보고서는 paragraph/bullets/chart와 trend/factors/weekday/compare/ratio5종, 질문·굵게·증감·생성 시각·스크롤을 지원한다. 그래프는 저장 JSON으로 FE가 그리며 Tableau 추가 뷰가 아니다.

## Agent·추천·저장

5종 screenType과 ID/조건을 보내고 서버가 권한/데이터를 확인한다. 예시 질문·Enter/Shift+Enter·실행 중 입력/추천 차단·완료 단계 접기/펼치기를 제공한다. text/list/resourceCards·조건 met/unmet/unknown을 렌더링한다.

추천은 API-03을 공유한다. 비식별 상담의 필요 지원, 같은 동/시군구 전체, 연령/성별 무관을 반영한다. 진행 자원이 없으면 종료까지 넓혔다고 알리고 상담 없음/결과 없음도 처리한다. 데모 최대3개·낱말 순위는 기준안이며 AI 담당이 품질/순위를 검수한다. 이유·조건·이용 전 확인·근거·최신 상세 링크를 보존한다.

신규 conversationId는 예약값이다. FE는 실행 예약 ID와 다음 질문에 쓸 확정 ID를 구별한다. done/completed 뒤에만 확정하고 신규 첫 질문 failed/만료 뒤 새 실행은 null로 시작한다. 기존 저장 대화 실패는 기존 ID를 유지한다. 재접속은 같은 run만 복구하고 POST를 자동 반복하지 않는다.

질문/상담/답변 신원을 제거하고 완료 turn의 question·answer_blocks·progress_steps·completed_at만 저장한다. 패널의 사용자 입력 원문 표시는 로컬이다. 새 대화·화면 간 유지·사용자 전환 초기화·이력 복원·마지막 완료 서울일+3개월·말일 보정·삭제·지연 응답 차단을 지원한다.

## 탈퇴·배치·개발 도구

유일 사례자와 진행 중 자원을 개별/일괄 인계하고 최종 암호 오류는 창에 남긴다.409이면 재조회하되 유효한 선택을 보존한다. 인계 대상이 있을 때만 후임 부재로 막는다. 모두0이면 빈 배열 탈퇴가 가능하다. 종료 자원/상담 기록자 FK를 유지하고 대화/세션을 정리한다.

화면 없는2.2.1은 DE1으로 등록한다. 부분 적재·재실행·보고서 CASCADE 후 재생성·게시 월 동기화를 검수한다. /flow의 강조/열기/SVG 저장, 사용자 전환·메일함·예외·API 로그는 개발 검수 범위다.


## 개정 2.2.0 추가 계약

인증 코드는 SMTP 메일로만 전달한다. 가입 증명 verificationToken은 API-06 성공 응답으로 전달하고 API-07 요청에서 한 번 사용한다. 코드와 가입 증명은 DB에 해시로만 저장하며 원문을 로그에 남기지 않는다.

resourceName은 trim 후 최대 50자의 자원명 부분 검색이며 공백만 있으면 조건을 생략한다. 다른 필터와 AND로 결합하고 퍼센트·밑줄·역슬래시는 문자 그대로 처리한다. sort=resourceName은 정렬 조건으로 구분한다.

manager는 정상 응답에서 항상 객체이며 withdrawn은 v_resource_summary.manager_withdrawn을 전달한다. 표시 상태 status=종료이고 withdrawn=true일 때만 name을 퇴사자로, title을 null로 반환하며 memberId와 orgName은 유지한다. 수동 종료와 종료일 경과에 따른 자동 종료 모두 포함한다. 진행 중 자원은 탈퇴 전에 활성 후임에게 인계해 후임 이름을 표시한다. 진행 중인데 탈퇴 담당자가 남으면 정합성 오류로 기록하고 정상 상세 응답 대신 500을 반환한다. manager=null을 퇴사 표시로 사용하지 않는다.

FR-082 서울 날짜 기준 매일 한 번 delete_scheduled_at <= current_date인 대화를 물리 삭제하고 turn은 FK CASCADE로 함께 정리한다. 삭제 전에 관련 실행을 무효화해 늦은 답변 저장을 차단한다. 일일 실행 시각은 운영 설정으로 정한다. 삭제는 대화 단위의 원자 처리를 적용하며 실패한 대상은 재실행 또는 다음 예약 실행에서 재시도한다. 반복 실행은 유효 대화를 보존하고 이미 삭제된 대화는 건너뛴다. 실행 일시·성공/실패·삭제 건수와 오류 추적 ID를 기록하고 질문·답변 원문은 로그에 남기지 않는다. 배치 실패 중에도 만료 대화는 목록·상세·후속 실행에서 제외한다.
