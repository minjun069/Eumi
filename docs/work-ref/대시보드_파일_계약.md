# Tableau 게시 데이터 계약

기준 DB는 public.dim_region·region_result 및 analysis의 격자·지표·기여도 테이블이다. export는 eumi_pipeline 또는 승인된 데이터 작업 계정에서 수행한다. eumi_app은 analysis를 읽지 않는다. 분석 DB 재적재와 Public 게시 갱신은 별도 작업이며 마지막 게시 성공 시각과 대상 월을 운영 기록으로 남긴다.

동 단위 출력은 dongCode 문자열 10자리·sigunguCode 5자리·month YYYY-MM·bgScore·bgGrade·bhScore·bhGrade·riskGrade를 포함한다. region_result의 값 없는 동은 행이 없으며 0점으로 보완하지 않는다. 격자 출력은 gridCode·dongCode·month·anomalyScore·gx·gy를 사용한다. anomalyScore 결측은 null이며 등급으로 오인하지 않는다. 경계 geometry와 gx·gy 좌표계는 원본이 미정의하므로 데이터 담당의 좌표계·행정동 귀속 코드표를 게시 작업의 선행 조건으로 둔다.

기여도는 month·dongCode·indicatorCode·contribution이며 indicatorCode는 bh_region_indicator 컬럼명과 일치한다. 전월 변화 요인은 현재 기여도-전월 기여도로 계산한다. 전월 결과가 없으면 계산 불가로 표시한다. 세부 지표의 코드·단위·결측 의미는 V6 주석과 데이터 담당 코드표를 따른다. 매월 1일 DATE 저장을 출력 시 YYYY-MM로 변환한다. 현재 DB에 analysis_release·게시 manifest 테이블이 있다고 가정하지 않는다.

Public에는 공개 가능한 집계·합성 자료만 게시한다. 회원·사례자·상담·세션·대화 원문은 게시 대상이 아니다.


## 최종 점검의 미확정 의미

[상세 계약](프로토타입_기능_상세_계약.md)의 대시보드 절을 적용한다. bg/bh 도시 내 등급·데모 고정 컷·종합 riskGrade·③ 상위20%=1분위는 같은 개념이 아니다. ②의 의미와 격자3단계/null/좌표계/SRID/geom은 DE1에서 확정한다. 저장소와 ERD로 산식을 확정했다고 판단하지 않는다.
