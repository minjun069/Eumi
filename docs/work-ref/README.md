# 작업 참고 (임시)

작업하는 동안 볼 저장소 밖 문서의 **사본**을 둔다. 기준 문서가 아니다. 기준은 [docs/spec](../spec/README.md) · [docs/api](../api/) · [docs/decisions](../decisions/)이다.

## 규칙

1. **넣을 때:** 아래 표에 한 줄을 추가한다. 원본 위치, 원본 날짜, 쓰는 작업, 지울 조건을 적는다. 사본 내용은 고치지 않는다.
2. **기준 문서와 다를 때:** 기준 문서를 따른다. 결정이 바뀌었으면 사본이 아니라 기준 문서를 고친다.
3. **다 쓰면:** 그 작업의 마지막 MR에서 파일과 표의 줄을 함께 지운다. 계속 기준으로 남길 내용이 있으면, 지우기 전에 docs/spec이나 docs/api로 옮긴다.
4. **넣지 않는 것:** 비밀값(비밀번호 · 키 · 토큰)과 실제 개인정보.
