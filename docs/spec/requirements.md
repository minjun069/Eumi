### FR-082 만료 대화 일일 물리 삭제
- 영역: 운영 배치
- 요구사항 상세와 처리 결과: 서울 날짜 기준 매일 한 번 delete_scheduled_at <= current_date인 대화를 물리 삭제하고 메시지는 FK CASCADE로 함께 정리한다. 실행 중인 대화는 삭제 전에 취소를 요청하고, 삭제 뒤 늦게 들어오는 AI 행은 FK로 거부된다. 일일 실행 시각은 운영 설정으로 정한다. 삭제는 대화 단위의 원자 처리를 적용하며 실패한 대상은 재실행 또는 다음 예약 실행에서 재시도한다. 반복 실행은 유효 대화를 보존하고 이미 삭제된 대화는 건너뛴다. 실행 일시·성공/실패·삭제 건수와 오류 추적 ID를 기록하고 질문·답변 원문은 로그에 남기지 않는다. 배치 실패 중에도 만료 대화는 목록·상세·후속 실행에서 제외한다.
- 대상 및 입력 조건: 백엔드 스케줄러·운영 담당<br>Asia/Seoul 현재 날짜와 delete_scheduled_at이 지난 대화
- 검증 기준: 기한 전 유지·기한 당일 삭제·메시지 CASCADE·반복 실행 안전·실패 재시도·실행 기록·원문 로그 없음·늦은 AI 행 거부
- 기능 및 API와 작업: 운영 배치<br>내부 배치·공개 REST 없음<br>작업 AI2,I1
- 정의 상태: 구현 기준
