| GMS 크레딧 합계 | 808 | 3,469 |
| 실행 기록 크기 (질문 하나) | 16 ~ 34MB | 14 ~ 34MB, 끝난 뒤 기록 공간 398MB / 512MB |

- 최종 답변 시간은 거의 전부 AI 처리(모델 호출 12번 안팎)다. 5명이 동시에 물어도 1명일 때보다 길어지지 않았고, 화면 API 응답도 그대로였다.
- **실패 2건의 원인:** 모델 호출 1번이 GMS에서 HTTP 520(GMS 앞단 Cloudflare 오류)을 받았고, AI는 호출을 다시 시도하지 않고 질문을 실패로 끝냈다. 모델 호출 기준 248번 중 2번(0.8%)인데, 질문 하나가 12번쯤 부르므로 질문 기준 실패율이 15%가 됐다. 실패를 정리할 때 `error.code`가 비어 AI 내부 검증 오류가 한 번 더 난다(11/10에 적어 둔 문제). 단독 단계(52번 호출)에서는 없었다.
- **실행 기록 공간:** 운영 ai는 실행 기록을 메모리 공간 512MB에 쓴다. 자료 조회가 있는 질문 약 25건이면 가득 찬다. 가득 차면 그 뒤 질문이 실패할 수 있어, 시험 뒤와 시연 전에 ai를 재시작해 비운다.
- GMS 크레딧 = 입력 1k 토큰당 1 + 출력 1k 토큰당 5 (gpt-6-luna). GMS 사용 내역 · 사용 크레딧 증가분과 세 번 맞춰 봤고 같았다.
- 개선 필요 여부: **필요 (AI).** 모델 호출 5xx 재시도, `error.code` null, 실행 기록 크기. 인프라: 기록 공간 확대 또는 디스크 전환(시연 뒤).
