## 저장소에 넣지 않은 것

아래는 김민재 PC의 측정 도구 폴더(`INFRA/_claude_tmp/perf/`)에 있다. 결과 문서가 가리키는 파일 이름은 그 폴더 기준이다.

- 측정 도구: Playwright 화면 흐름, k6 부하, 서버 기록 · 요약 스크립트 (`perf-collect.sh` · `ai-usage.sh` · `perf-nginx.sh`)
- 측정 원본: `results/` (1회차) · `results/r2/` (2회차) · `results/nginx/` (11/15 Nginx 처리 시간)
- 대시보드 사본: 회차별 · 종합 HTML과 PDF, 그 데이터 CSV (`dashboard-data*/`)

시험 계정의 비밀번호와 토큰은 어느 파일에도 남기지 않았다.

- 운영 서버에서 재므로 팀에 시간을 미리 알린다. 실제 AI 질문은 GMS 크레딧을 쓴다 (gpt-6-luna 기준 질문 하나에 중앙값 166).
