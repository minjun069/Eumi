## 1. SSAFY GMS (LLM API)

| 항목 | 내용 |
|---|---|
| 용도 | AI Agent 서버의 모델 호출 (AI 대화 패널 답변, 인사이트 보고서 작성 · 검토) |
| 가입 · 발급 | SSAFY 교육생 계정으로 GMS에 로그인해 API 키를 발급합니다 (AI 담당 발급) |
| 연결 방식 | OpenAI 호환 API. 주소 `https://gms.ssafy.io/gmsapi/api.openai.com/v1` |
| 모델 | `gpt-6-luna` |
| 설정 | 주소 · 모델은 운영 compose의 `SETTINGS_BASE_URL` · `SETTINGS_MODEL` (비밀값 아님), 키는 `.env.config`의 `EUMI_LLM_API_KEY` → compose가 `SETTINGS_API_KEY`로 넘김 |
| 비용 | GMS 크레딧. `gpt-6-luna` 기준 입력 1,000토큰당 1 + 출력 1,000토큰당 5. 질문 하나에 중앙값 166, 보고서 한 건(동 하나)에 약 1,000 ~ 2,400 |

**주의**
- AI 코드의 기본 모델은 `gpt-6-sol`입니다. 운영 compose와 로컬 `ai/.env`에 `SETTINGS_MODEL=gpt-6-luna`를 꼭 둡니다. 빠지면 크레딧이 훨씬 빨리 줄어듭니다.
- 키가 새어 나갔다고 의심되면 GMS에서 다시 발급하고 `.env.config` 값을 바꾼 뒤 ai를 다시 배포합니다.

서버에서 GMS로 나가는 길만 확인하기 (jenkins 계정, 키는 보내지 않음). `200` · `401` · `404`가 나오면 열려 있고, 연결 오류 · 시간 초과면 막힌 것입니다:

```bash
cd /srv/eumi
scripts/dc.sh --profile ai exec -T ai /app/.venv/bin/python -c "import os, httpx; u = os.environ['SETTINGS_BASE_URL'].rstrip('/'); print(httpx.get(u + '/models', timeout=5).status_code)"
```

## 2. Tableau Public

| 항목 | 내용 |
|---|---|
| 용도 | 고립 위험 탐색 지도 · 그래프, 읍면동 100m 격자 지도, 인사이트 보고서 그래프 8종 |
| 가입 | Tableau Public 무료 계정 (public.tableau.com). 워크북은 공개로만 게시됩니다 |
| 게시본 | 워크북 `eumi_tableau_main_dashboard_v_master` — `https://public.tableau.com/views/eumi_tableau_main_dashboard_v_master` (데이터 분석 담당 계정에 게시) |
| 임베드 | Embedding API v3 스크립트 `https://public.tableau.com/javascripts/api/tableau.embedding.3.latest.min.js` |
| 설정 | 화면 쪽 주소 · 시트 이름은 `frontend/src/tableau/tableauConfig.ts`, 시트 · 매개변수 목록은 `docs/work-ref/tableau_views.json`. 키는 필요 없습니다 |

**주의**
- 누구나 볼 수 있는 공개 게시본이라 개인정보 없이 분석 결과만 올립니다.
- 게시본은 서비스 DB와 실시간으로 연결되지 않습니다. 분석 결과가 바뀌면 워크북을 다시 게시해야 화면 그래프에 반영됩니다.
- 워크북 이름이나 시트 이름을 바꾸면 화면에서 그래프가 뜨지 않습니다. 다시 게시할 때는 같은 이름을 유지합니다.
- 첫 표시 속도(3 ~ 5초)는 Tableau Public 서버에 달려 있어 우리 서버와 무관합니다.

## 3. 공공데이터포털 (아파트 실거래가 API)

| 항목 | 내용 |
|---|---|
| 용도 | 아파트 매매 · 전월세 실거래가 월별 수집 (AI 분석 근거) |
| 사용 API | 국토교통부 아파트 매매 실거래가 상세 자료(`RTMSDataSvcAptTradeDev`), 국토교통부 아파트 전월세 실거래가 자료(`RTMSDataSvcAptRent`) |
| 가입 · 발급 | data.go.kr 회원가입 → 위 두 API 활용신청 → 마이페이지의 **일반 인증키 (Decoding)** 값 |
| 설정 | `.env.config`의 `DATA_GO_KR_SERVICE_KEY` (로컬은 `infra/.env`) |
| 호출 | `https://apis.data.go.kr/1613000/…`, 인자 `LAWD_CD`(강남구 11680 · 춘천시 51110) · `DEAL_YMD`(YYYYMM) · `pageNo` · `numOfRows`(1000), 응답 XML |
| 쓰는 코드 | `data/pipeline/common/apt_api.py`, `data/pipeline/m1_collect/collect_apt_trade.py` |

**호출 방식**
- 페이지 사이 0.2초 간격을 둡니다.
- 실패하면 대기 시간을 늘려 가며 다시 시도합니다. 키 · 승인 · 한도 오류는 다시 시도해도 같아서 바로 멈춥니다.
- 받은 건수가 응답의 전체 건수(`totalCount`)와 다르면 실패로 처리합니다.

## 참고: 원본 데이터 출처 (파일)

원본은 저장소에 없고, 서비스 재현에는 필요 없습니다 (분석 결과는 `db/seed`와 DB 덤프에 포함).

외부 API가 아니라 파일로 받아 쓰는 데이터입니다. 파이프라인을 다시 돌릴 때는 원본(약 2 GB)을 서버 MinIO(`sgi/raw/`)에 올려 씁니다 ([data/README.md](../data/README.md)).

| 데이터 | 쓰는 곳 | 제공처 |
|---|---|---|
| 주민등록 인구 (행정동, 월별) | 배경 지표 | 행정안전부 주민등록 인구통계 |
| 등록센서스 (가구 · 주택, 연간) | 배경 지표 | 통계청 |
| SGIS 100m 격자 통계 | 격자 배경 지표 | 통계청 SGIS 통계지리정보서비스 |
| SKT 유동인구 (50m, 월평균) | 행동 지표 · 시간 단위 유동 생성 | SK텔레콤 |
| 공원 · 버스정류장 | 배경 지표 | 데이터 분석 파트가 정리한 파일 |
| 행정동 경계 | 지도 · 격자 소속 동 | 데이터 분석 파트가 정리한 파일 |
